# ระบบนัดคิวเทคนิคพิเศษ
กลุ่มงานรังสีรักษา โรงพยาบาลมะเร็งลำปาง

ใช้นัดคิวผู้ป่วยที่ฉายรังสีด้วยเทคนิคพิเศษ และดูภาพรวมนัดหมายในรูปแบบปฏิทิน

## ความสามารถ

- **เทคนิค**: DIBH, SRS, SRT, SBRT และ **อื่นๆ** (กรอกชื่อเทคนิคเอง เช่น TBI, VMAT)
- **ข้อมูลผู้ป่วย**: HN, ชื่อ-สกุล, จำนวนครั้ง (Fx), หมายเหตุ
- **ตำแหน่ง / อวัยวะที่ฉาย (เลือกจากรายการ)**: Lt Breast, Chest, Abd, Head, H&N, Pelvis
  (เพิ่ม/แก้ที่ `sites.json` แล้วรัน `npm run build`)
- **แพทย์ผู้สั่ง (บังคับเลือก)**: ทัศน์วรรณ อาษากิจ, ศิริรัตน์ เชื้อสำราญ, พัฒธิดา มโนรส, ทินกร จอมใจ
  (เพิ่ม/แก้รายชื่อที่ `physicians.json` แล้วรัน `npm run build`)
- **วันเริ่มฉายและเวลานัด**
  - ระบบสร้างตารางวันฉายทุก Fx ให้อัตโนมัติ ข้ามวันเสาร์-อาทิตย์และวันหยุดราชการ
  - **ความถี่ในการฉาย**: Daily (ทุกวันทำการ), EOD (วันเว้นวัน), BID (วันละ 2 ครั้ง มีเวลานัดรอบ 2 แยก ควรห่างกัน ≥ 6 ชั่วโมง)
  - กด **“งด”** ที่วันใดก็ได้ เพื่อเลื่อนวันฉายนั้นออกไป (กด “ยกเลิกงด” เพื่อคืน)
  - ใส่เวลานัดและระยะเวลาต่อครั้ง ระบบจะ**ตรวจเวลาซ้อน**กับผู้ป่วยรายอื่นทุกวันฉาย
  - ปุ่ม **“หาเวลาว่างอัตโนมัติ”** หาเวลาที่ว่างตรงกันทุกวันฉาย (08:00–16:30 น. ทุก 5 นาที ปรับได้ที่ `WORK_START` / `WORK_END`)
- **การทำ CBCT**
  - CBCT ครั้งแรกทำในวันเริ่มฉาย (Fx 1) ทุกรูปแบบ ยกเว้น “ไม่ทำ CBCT ระหว่างฉาย”
  - รูปแบบ CBCT ระหว่างฉาย: 3 ครั้งแรก แล้วสัปดาห์ละครั้ง / Fx 1, 2, 3, 6, 11 / สัปดาห์ละครั้ง / ทุกครั้ง / เฉพาะครั้งแรก / ไม่ทำ / กำหนดเอง
  - **ค่าเริ่มต้นตามเทคนิค** (ปรับได้ที่ `TECH_DEFAULTS`): DIBH = Fx 1, 2, 3, 6, 11 (และตำแหน่ง Lt Breast),
    SRS = ทุกครั้ง, SBRT = ทุกครั้ง, เทคนิคอื่น = 3 ครั้งแรก แล้วสัปดาห์ละครั้ง
  - คลิกช่อง CBCT ในตาราง หรือคลิกวันในมุมมอง “ปฏิทินรายเดือน” เพื่อเลือกวันทำ CBCT เอง
- **แดชบอร์ดปฏิทินรายเดือน** ที่**เริ่มสัปดาห์ด้วยวันอาทิตย์** แสดงเดือนและปีเป็นภาษาไทย (พ.ศ.)
  - เลือกแสดง: วันเริ่มฉาย + CBCT (ค่าเริ่มต้น) / ทุกวันที่ฉาย / เฉพาะวันเริ่มฉาย
  - แยกสีตามเทคนิค มีป้าย `เริ่ม`, `Fx n` และ `CBCT` แสดงชื่อวันหยุดในปฏิทิน
  - สรุปจำนวนผู้ป่วยที่เริ่มฉายในเดือน แยกตามเทคนิค และจำนวนครั้งที่ทำ CBCT
  - คลิกวันที่เพื่อดูรายละเอียด กด `+` เพื่อเพิ่มนัด คลิกนัดเพื่อแก้ไขหรือลบ
  - กรองตามเทคนิค ค้นหาด้วย HN หรือชื่อ ส่งออก CSV รายเดือน และพิมพ์ปฏิทิน
- เตือนเมื่อ HN เดียวกันมีคอร์สฉายที่วันฉายทับกัน

## วันหยุด

รายการวันหยุดเริ่มต้นอยู่ใน `holidays.json` (วันหยุดราชการปี 2569 ตามประกาศ และวันหยุดวันที่ตายตัวของปี 2570)
**วันหยุดทางพุทธศาสนาของปี 2570 ยังไม่ประกาศ ต้องเพิ่มเองเมื่อมีประกาศ** รวมถึงวันปิดเครื่องหรือวันหยุดพิเศษของหน่วยงาน

- เวอร์ชัน Node: คัดลอก `holidays.json` ไปไว้ใน `data/holidays.json` แล้วแก้ไขไฟล์นั้น
- เวอร์ชัน Apps Script: แก้ไขในชีต **“วันหยุด”** ได้โดยตรง

## การติดตั้งและใช้งาน

ต้องมี [Node.js](https://nodejs.org) เวอร์ชัน 18 ขึ้นไป (ไม่ต้องติดตั้งแพ็กเกจเพิ่ม)

```bash
cd rt-queue
npm start
```

จากนั้นเปิด `http://localhost:3000` หรือเปิดจากเครื่องอื่นในเครือข่ายของโรงพยาบาลด้วย
`http://<IP ของเครื่องเซิร์ฟเวอร์>:3000` ทุกเครื่องจะเห็นข้อมูลชุดเดียวกัน

ตัวแปรสภาพแวดล้อมที่ตั้งค่าได้:

| ตัวแปร | ค่าเริ่มต้น | ความหมาย |
| --- | --- | --- |
| `PORT` | `3000` | พอร์ตของเว็บ |
| `HOST` | `0.0.0.0` | ที่อยู่ที่รับการเชื่อมต่อ (ใช้ `127.0.0.1` ถ้าต้องการให้เปิดได้เฉพาะเครื่องนี้) |
| `DATA_DIR` | `rt-queue/data` | โฟลเดอร์เก็บไฟล์ข้อมูล `bookings.json` |

### โหมดออฟไลน์

ถ้าเปิดไฟล์ `public/index.html` โดยตรง (ไม่ผ่านเซิร์ฟเวอร์) ระบบจะเก็บข้อมูลไว้ในเบราว์เซอร์ของเครื่องนั้นเท่านั้น
ข้อมูลจะไม่แชร์กับเครื่องอื่น มุมขวาบนของหน้าจะแสดงว่ากำลังใช้โหมดใด

## เวอร์ชัน Google Apps Script (เก็บข้อมูลใน Google Sheets)

โฟลเดอร์ `apps-script/` มีไฟล์ `Code.gs` และ `Index.html` ใช้ได้โดยไม่ต้องมีเซิร์ฟเวอร์ของตัวเอง

1. สร้าง Google Sheet ใหม่ แล้วไปที่เมนู **ส่วนขยาย > Apps Script**
2. วางเนื้อหา `Code.gs` ลงในไฟล์ `Code.gs`
3. กด **+ > HTML** ตั้งชื่อไฟล์ว่า `Index` (ต้องตรงตัวพิมพ์) แล้ววางเนื้อหา `Index.html`
4. กด **ทำให้ใช้งานได้ > การทำให้ใช้งานได้รายการใหม่ > เว็บแอป**
   - ดำเนินการในฐานะ: **ฉัน**
   - ผู้มีสิทธิ์เข้าถึง: เลือกตามนโยบายของโรงพยาบาล เช่น เฉพาะบัญชีในองค์กร
5. อนุญาตสิทธิ์ แล้วเปิด URL ของเว็บแอปที่ได้

ระบบจะสร้างชีต `นัดเทคนิคพิเศษ` และ `วันหยุด` ให้อัตโนมัติเมื่อเปิดใช้งานครั้งแรก
ชีตที่สร้างจากเวอร์ชันก่อนจะถูกเพิ่มคอลัมน์ใหม่ให้เอง ข้อมูลเดิมยังใช้ได้
ถ้าเป็นสคริปต์แยก (สร้างจาก script.google.com) ระบบจะสร้าง Google Sheet ใหม่ใน Drive ของผู้ deploy ให้อัตโนมัติ
หรือจะใส่ ID ของชีตที่ต้องการเองใน `SPREADSHEET_ID` ใน `Code.gs` ก็ได้
ทุกครั้งที่แก้โค้ด ต้องกด **ทำให้ใช้งานได้ > จัดการการทำให้ใช้งานได้ > แก้ไข > เวอร์ชันใหม่** จึงจะเห็นผลที่ URL เดิม

## ข้อมูลและความปลอดภัย

- ข้อมูลทั้งหมดเก็บในไฟล์ `data/bookings.json` บนเครื่องเซิร์ฟเวอร์ ควรสำรองไฟล์นี้เป็นประจำ
- โฟลเดอร์ `data/` ถูกตั้งไว้ใน `.gitignore` เพื่อไม่ให้ข้อมูลผู้ป่วยถูก commit ขึ้น Git
- ระบบนี้ไม่มีการล็อกอิน จึงควรเปิดใช้งานเฉพาะในเครือข่ายภายในของโรงพยาบาล

## API

| Method | Path | คำอธิบาย |
| --- | --- | --- |
| `GET` | `/api/bookings` | รายการนัดทั้งหมด |
| `POST` | `/api/bookings` | สร้างนัดใหม่ |
| `PUT` | `/api/bookings/:id` | แก้ไขนัด |
| `DELETE` | `/api/bookings/:id` | ลบนัด |

ตัวอย่างข้อมูลนัด:

```json
{
  "hn": "650123",
  "name": "นางสมศรี ใจดี",
  "technique": "DIBH",
  "techniqueOther": "",
  "site": "Lt. breast",
  "startDate": "2026-10-07",
  "time": "09:00",
  "fractions": 15,
  "cbct": true,
  "physician": "",
  "note": ""
}
```

`technique` ต้องเป็นหนึ่งใน `DIBH`, `SRS`, `SRT`, `SBRT`, `อื่นๆ` (ถ้าเป็น `อื่นๆ` ต้องระบุ `techniqueOther`)

## การแก้ไขโค้ด

แก้หน้าจอที่ `public/index.html` เท่านั้น แล้วรัน `npm run build` เพื่อสร้าง `apps-script/Index.html`
และใส่รายการวันหยุดจาก `holidays.json` รายชื่อแพทย์จาก `physicians.json` และตำแหน่งที่ฉายจาก `sites.json` ลงในไฟล์ต่างๆ ให้ตรงกัน
