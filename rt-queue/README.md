# ระบบนัดคิวเทคนิคพิเศษ
กลุ่มงานรังสีรักษา โรงพยาบาลมะเร็งลำปาง

ใช้นัดคิวผู้ป่วยที่ฉายรังสีด้วยเทคนิคพิเศษ และดูภาพรวมนัดหมายในรูปแบบปฏิทิน

## ความสามารถ

- **เทคนิค**: DIBH, SRS, SRT, SBRT และ **อื่นๆ** (กรอกชื่อเทคนิคเอง เช่น TBI, VMAT)
- **ข้อมูลที่กรอก**: HN, ชื่อ-สกุล, เทคนิค, **วันเริ่มฉายรังสี**, **CBCT (ทำ / ไม่ทำ)**
  และข้อมูลเพิ่มเติม ได้แก่ ตำแหน่งที่ฉาย เวลา จำนวนครั้ง (Fx) แพทย์ผู้สั่ง และหมายเหตุ
- **แดชบอร์ดปฏิทินรายเดือน** ที่**เริ่มสัปดาห์ด้วยวันอาทิตย์** แสดงเดือนและปีเป็นภาษาไทย (พ.ศ.)
  - แยกสีตามเทคนิค และมีป้าย `CBCT` บนนัดที่ต้องทำ CBCT
  - สรุปจำนวนนัดของเดือนแยกตามเทคนิค และจำนวนผู้ป่วยที่ทำ CBCT
  - คลิกวันที่ในปฏิทินเพื่อดูรายละเอียดนัดของวันนั้น หรือกด `+` เพื่อเพิ่มนัดในวันนั้น
  - คลิกนัดเพื่อแก้ไขหรือลบ
  - กรองตามเทคนิค ค้นหาด้วย HN หรือชื่อ
  - ส่งออก CSV รายเดือน (เปิดด้วย Excel ได้) และพิมพ์ปฏิทิน
- เตือนเมื่อ HN เดียวกันมีนัดในวันเดียวกันอยู่แล้ว

## การติดตั้งและใช้งาน

ต้องมี [Node.js](https://nodejs.org) เวอร์ชัน 18 ขึ้นไป (ไม่ต้องติดตั้งแพ็กเกจเพิ่ม)

```bash
cd rt-queue
npm start
```

จากนั้นเปิด `http://localhost:3000` หรือเปิดจากเครื่องอื่นในเครือข่ายของโรงพยาบาลด้วย
`http://<IP ของเครื่องเซิร์ฟเวอร์>:3000` ทุกเครื่องจะเห็นข้อมูลชุดเดียวกัน

ตัวแปรสภาพแวดล้อมที่ตั้งค่าได้:

| ตัวแปร | ค่าเริ่มต้น | ความหมาย |
| --- | --- | --- |
| `PORT` | `3000` | พอร์ตของเว็บ |
| `HOST` | `0.0.0.0` | ที่อยู่ที่รับการเชื่อมต่อ (ใช้ `127.0.0.1` ถ้าต้องการให้เปิดได้เฉพาะเครื่องนี้) |
| `DATA_DIR` | `rt-queue/data` | โฟลเดอร์เก็บไฟล์ข้อมูล `bookings.json` |

### โหมดออฟไลน์

ถ้าเปิดไฟล์ `public/index.html` โดยตรง (ไม่ผ่านเซิร์ฟเวอร์) ระบบจะเก็บข้อมูลไว้ในเบราว์เซอร์ของเครื่องนั้นเท่านั้น
ข้อมูลจะไม่แชร์กับเครื่องอื่น มุมขวาบนของหน้าจะแสดงว่ากำลังใช้โหมดใด

## เวอร์ชัน Google Apps Script (เก็บข้อมูลใน Google Sheets)

โฟลเดอร์ `apps-script/` มีไฟล์ `Code.gs` และ `Index.html` ใช้ได้โดยไม่ต้องมีเซิร์ฟเวอร์ของตัวเอง

1. สร้าง Google Sheet ใหม่ แล้วไปที่เมนู **ส่วนขยาย > Apps Script**
2. วางเนื้อหา `Code.gs` ลงในไฟล์ `Code.gs`
3. กด **+ > HTML** ตั้งชื่อไฟล์ว่า `Index` (ต้องตรงตัวพิมพ์) แล้ววางเนื้อหา `Index.html`
4. กด **ทำให้ใช้งานได้ > การทำให้ใช้งานได้รายการใหม่ > เว็บแอป**
   - ดำเนินการในฐานะ: **ฉัน**
   - ผู้มีสิทธิ์เข้าถึง: เลือกตามนโยบายของโรงพยาบาล เช่น เฉพาะบัญชีในองค์กร
5. อนุญาตสิทธิ์ แล้วเปิด URL ของเว็บแอปที่ได้

ระบบจะสร้างชีตชื่อ `นัดเทคนิคพิเศษ` ให้อัตโนมัติเมื่อบันทึกนัดครั้งแรก
ถ้าเป็นสคริปต์แยกที่ไม่ได้สร้างจาก Google Sheet ให้ใส่ ID ของชีตใน `SPREADSHEET_ID` ใน `Code.gs`
ทุกครั้งที่แก้โค้ด ต้องกด **ทำให้ใช้งานได้ > จัดการการทำให้ใช้งานได้ > แก้ไข > เวอร์ชันใหม่** จึงจะเห็นผลที่ URL เดิม

## ข้อมูลและความปลอดภัย

- ข้อมูลทั้งหมดเก็บในไฟล์ `data/bookings.json` บนเครื่องเซิร์ฟเวอร์ ควรสำรองไฟล์นี้เป็นประจำ
- โฟลเดอร์ `data/` ถูกตั้งไว้ใน `.gitignore` เพื่อไม่ให้ข้อมูลผู้ป่วยถูก commit ขึ้น Git
- ระบบนี้ไม่มีการล็อกอิน จึงควรเปิดใช้งานเฉพาะในเครือข่ายภายในของโรงพยาบาล

## API

| Method | Path | คำอธิบาย |
| --- | --- | --- |
| `GET` | `/api/bookings` | รายการนัดทั้งหมด |
| `POST` | `/api/bookings` | สร้างนัดใหม่ |
| `PUT` | `/api/bookings/:id` | แก้ไขนัด |
| `DELETE` | `/api/bookings/:id` | ลบนัด |

ตัวอย่างข้อมูลนัด:

```json
{
  "hn": "650123",
  "name": "นางสมศรี ใจดี",
  "technique": "DIBH",
  "techniqueOther": "",
  "site": "Lt. breast",
  "startDate": "2026-10-07",
  "time": "09:00",
  "fractions": 15,
  "cbct": true,
  "physician": "",
  "note": ""
}
```

`technique` ต้องเป็นหนึ่งใน `DIBH`, `SRS`, `SRT`, `SBRT`, `อื่นๆ` (ถ้าเป็น `อื่นๆ` ต้องระบุ `techniqueOther`)
