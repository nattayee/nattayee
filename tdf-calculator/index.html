Fractionated (Orton & Ellis 1973)

TDF = 1.19 · N · d1.538 · X−0.169
  • N จำนวน fraction, d dose ต่อ fraction (Gy)
  • X ระยะห่างเฉลี่ยระหว่าง fraction (วัน) = 7 / (fx ต่อสัปดาห์) หรือ T/N
  • มาจาก NSD = D · N−0.24 · T−0.11 ผ่าน TDF = 10−3 · NSD1.538
  • TDF รวมกันได้แบบบวกตรง (additive) ระหว่างแต่ละช่วงการรักษา

Decay factor เมื่อพักฉาย

TDFหลังพัก = TDFก่อนพัก · (T / (T + R))0.11
  • T จำนวนวันตั้งแต่เริ่มฉายจนถึงวันเริ่มพัก
  • R จำนวนวันที่พัก (rest interval)
  • Split course: TDFรวม = TDF₁ · (T/(T+R))0.11 + TDF₂
  • หลายช่วงพัก: ใช้ factor กับ TDF สะสมก่อนแต่ละช่วงพัก โดยนับ T จากวันเริ่มรักษา

Brachytherapy (Orton 1974)

TDF = 4.76×10−3 · r1.35 · t
TDF = 4.76×10−3 · r₀1.35 · (1 − e−1.35λt) / (1.35λ)
  • r dose rate (cGy/h), t เวลา (ชม.), λ = ln2 / T½ (ต่อชั่วโมง)
  • Permanent implant (t → ∞): TDF = 4.76×10−3 · r₀1.35 / (1.35λ), dose = r₀/λ
  • ข้อมูลต้นแบบครอบคลุม dose rate ≳ 25 cGy/h; ต่ำกว่านั้นเป็นการ extrapolate

ตาราง TDF ต่อ fraction

TDF ต่อ 1 fraction ตาม dose/fraction (แถว) และจำนวน fraction ต่อสัปดาห์ (คอลัมน์) · คูณด้วย N เพื่อได้ TDF ของ course

Br J Radiol 1974;47:603–607 · Ellis F. Dose, time and fractionation: a clinical hypothesis. Clin Radiol 1969;20:1–7.
