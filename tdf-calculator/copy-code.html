TDF Dose Calculator · โค้ด Apps Script

โปรเจกต์ Apps Script ใช้ไฟล์เดียว คือ รหัส.gs หน้าเว็บโหลดจาก GitHub อัตโนมัติ จึงไม่ต้องวางไฟล์ Index อีกต่อไป

  1. เปิดโปรเจกต์ Apps Script ของ TDF (หรือ script.google.com → New project)
  2. เปิด รหัส.gs กด Ctrl+A ลบของเดิมทั้งหมด แล้ววางโค้ดจากกล่องด้านล่าง กดบันทึก
  3. ลบไฟล์ Index (และ Tdf ถ้ามี) ออกจากโปรเจกต์ โดยกด ⋮ ข้างชื่อไฟล์ → ลบ
  4. เลือกฟังก์ชัน setup ที่แถบด้านบน กด Run หนึ่งครั้ง และอนุญาตสิทธิ์ (Sheets, Drive และการเชื่อมต่อภายนอก)
  5. Deploy → Manage deployments → แก้ไข (ดินสอ) → Version: New version → Deploy · ครั้งแรกใช้ New deployment → Web app · Execute as: Me · Who has access: Anyone
  6. เปิดเว็บแล้วดูท้ายหน้า ต้องเห็น “เวอร์ชัน …” ตรงกับด้านล่างของหน้านี้
