# ระบบจัดการวันลา — เวอร์ชัน Google Apps Script

ใช้ Google Sheet เป็นฐานข้อมูล ไม่ต้องมีเซิร์ฟเวอร์ ฟีเจอร์เหมือน `leave-app/` และเพิ่มอีก 2 อย่าง:
ส่งอีเมลแจ้งผลการอนุมัติให้พนักงาน และส่งออกรายงานเป็นแท็บใหม่ใน Google Sheet

## ติดตั้ง

1. สร้าง Google Sheet ใหม่ → ส่วนขยาย → Apps Script
2. วางเนื้อหา `Code.gs` แทนโค้ดเดิมใน Code.gs
3. เพิ่มไฟล์ HTML ชื่อ `Index` แล้ววางเนื้อหา `Index.html`
4. บันทึก เลือกฟังก์ชัน `setup` → เรียกใช้ → อนุญาตสิทธิ์
5. ทำให้ใช้งานได้ → เว็บแอป → ดำเนินการในฐานะ: ฉัน, ผู้มีสิทธิ์เข้าถึง: ทุกคน (หรือทุกคนในองค์กร)
6. เปิด URL `/exec` เข้าสู่ระบบด้วยอีเมล Google ของคุณ / `admin1234` แล้วเปลี่ยนรหัสผ่านทันที

ตั้งค่าเพิ่มเติมได้ที่หัวไฟล์ `Code.gs` (`ADMIN_PASSWORD`, `SEED_DEMO`, `SESSION_HOURS`)
หลังแก้โค้ด ต้อง Deploy เวอร์ชันใหม่ (จัดการการทำให้ใช้งานได้ → แก้ไข → เวอร์ชันใหม่)
