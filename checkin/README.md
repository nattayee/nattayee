# ระบบเช็กอินเจ้าหน้าที่แต่ละโซน

เว็บแอปสำหรับเช็กชื่อเจ้าหน้าที่ (อยู่ / ลา / ไม่ทราบ) ตามโซน โดยอ่านและบันทึกข้อมูลลง Google Sheet
[รายชื่อเจ้าหน้าที่แต่ละโซน](https://docs.google.com/spreadsheets/d/1-6yW-yDd3l6LDmkJUliJyPGggXpLm3edwrXDXZ7LxFM/edit) โดยตรง
สร้างด้วย Google Apps Script จึงไม่ต้องมีเซิร์ฟเวอร์

## ความสามารถ

- สรุปจำนวน **ทั้งหมด / อยู่ / ลา / ไม่ทราบ** ทั้งภาพรวมและรายโซน พร้อมแถบความคืบหน้า
- หน้าภาพรวมแสดงการ์ดของทุกโซน แท็บโซนแสดงจำนวนคนที่ยัง "ไม่ทราบ" สถานะ (✓ เมื่อครบ)
- รายชื่อแบ่งตามหน่วยงาน กดปุ่ม **อยู่ / ลา / ไม่ทราบ** แล้วบันทึกลงคอลัมน์ D (สถานะ) ในชีตทันที
- บันทึกเวลาที่อัปเดตล่าสุดในคอลัมน์ I (หัวคอลัมน์ "อัปเดตล่าสุด" จะถูกสร้างให้อัตโนมัติ)
- ค้นหาชื่อ ตำแหน่ง หรือหน่วยงานได้ทุกโซน และกดการ์ดสถานะด้านบนเพื่อกรอง เช่น ดูเฉพาะคนที่ "ไม่ทราบ"
- แสดงเบอร์โทร (คอลัมน์ G) เป็นลิงก์กดโทรได้ หากกรอกไว้ในชีต
- รีเฟรชข้อมูลอัตโนมัติทุก 20 วินาที ทำให้หลายคนเช็กชื่อพร้อมกันได้
- ปุ่มรีเซ็ตสถานะกลับเป็น "ไม่ทราบ" (รายโซนหรือทุกโซน) สำหรับการซ้อมครั้งถัดไป
- ใช้งานบนมือถือได้ รองรับโหมดมืด

## โครงสร้างชีตที่รองรับ

ระบบจะใช้ทุกแท็บที่มี `D2 = สถานะ` และ `E2 = ชื่อ-สกุล` (ตอนนี้คือ โซนที่ 1 – โซน8)

| คอลัมน์ | ข้อมูล |
| --- | --- |
| A (merge A:F) | ชื่อหน่วยงาน (แถวที่ 1 และแถวคั่นหน่วยงาน) |
| D | สถานะ: อยู่ / ลา / ไม่ทราบ |
| E | ชื่อ-สกุล (ถ้าขึ้นต้นด้วย `-` จะแสดงเป็นหมายเหตุ เช่น "- เช็ครายชื่อที่โซน 2 -") |
| F | ตำแหน่ง |
| G | เบอร์โทร |
| H | วันเกิด |
| I | อัปเดตล่าสุด (ระบบเขียนให้) |

เพิ่ม/ลบ/ย้ายรายชื่อหรือเพิ่มแท็บโซนใหม่ในชีตได้ตามปกติ ระบบจะอ่านใหม่ทุกครั้ง
ก่อนบันทึกจะตรวจชื่อในแถวก่อนเสมอ ถ้าแถวเลื่อนไปจะค้นหาชื่อในแท็บเดิมให้อัตโนมัติ

## วิธีติดตั้ง (ประมาณ 5 นาที)

1. เปิด Google Sheet แล้วไปที่เมนู **ส่วนขยาย → Apps Script**
2. ในไฟล์ `Code.gs` ลบโค้ดเดิมทั้งหมด แล้ววางเนื้อหาจาก [`Code.gs`](./Code.gs)
3. กด **+** ข้างคำว่า "ไฟล์" → **HTML** ตั้งชื่อว่า `Index` (ไม่ต้องใส่ .html) แล้ววางเนื้อหาจาก [`Index.html`](./Index.html)
4. (แนะนำ) ไปที่ ⚙️ **การตั้งค่าโปรเจ็กต์** ตั้งเขตเวลาเป็น `(GMT+07:00) Bangkok`
5. กด **บันทึก** แล้วกด **ทำให้ใช้งานได้ (Deploy) → การทำให้ใช้งานได้รายการใหม่**
   - ประเภท: **เว็บแอป**
   - เรียกใช้ในฐานะ: **ฉัน** (บัญชีเจ้าของชีต)
   - ผู้ที่มีสิทธิ์เข้าถึง: เลือกตามความเหมาะสม (ดูหัวข้อความปลอดภัยด้านล่าง)
6. กด **ทำให้ใช้งานได้** แล้วอนุญาตสิทธิ์เข้าถึงชีต (ครั้งแรกอาจเจอหน้า "Google ยังไม่ได้ยืนยันแอปนี้" ให้กด
   **ขั้นสูง → ไปที่ … (ไม่ปลอดภัย)** เพราะเป็นสคริปต์ของเราเอง)
7. คัดลอก **URL ของเว็บแอป** ไปแชร์ให้ผู้ใช้งาน (ทำเป็น QR Code ติดแต่ละโซนได้)

> แก้โค้ดภายหลัง: ต้องไปที่ **ทำให้ใช้งานได้ → จัดการการทำให้ใช้งานได้ → แก้ไข (✏️) → เวอร์ชัน: เวอร์ชันใหม่**
> URL เดิมจึงจะได้โค้ดใหม่

### ทางเลือก: ติดตั้งด้วย clasp

```bash
npm install -g @google/clasp
clasp login
clasp create --type standalone --title "ระบบเช็กอินเจ้าหน้าที่" --rootDir checkin
clasp push
clasp deploy
```

(`Code.gs` เปิดชีตด้วย `SPREADSHEET_ID` จึงใช้เป็นโปรเจ็กต์แบบ standalone ได้)

## ความปลอดภัย

เว็บแอปทำงานด้วยสิทธิ์ของผู้ deploy ทุกคนที่เข้า URL ได้จะ **เปลี่ยนสถานะในชีตได้**

- **ทุกคนในองค์กร (โดเมน)** – ปลอดภัยที่สุด หากเจ้าหน้าที่ใช้บัญชี Google ขององค์กร
- **ทุกคนที่มีบัญชี Google** – ต้องล็อกอิน Google ก่อนใช้งาน
- **ทุกคน** – ไม่ต้องล็อกอิน สะดวกที่สุดสำหรับการซ้อม แต่ใครได้ลิงก์ไปก็แก้ได้ ควรแชร์ลิงก์เฉพาะผู้เกี่ยวข้อง

ชีตต้นฉบับไม่จำเป็นต้องแชร์แบบแก้ไขได้ให้ผู้ใช้เว็บ

## การตั้งค่าใน `Code.gs`

| ค่า | ความหมาย |
| --- | --- |
| `SPREADSHEET_ID` | ID ของ Google Sheet |
| `COL_UPDATED` | คอลัมน์บันทึกเวลาอัปเดต (ค่าเริ่มต้น 9 = I) ตั้งเป็น `0` หากไม่ต้องการ |
| `STATUSES` | ตัวเลือกสถานะ ต้องตรงกับ Data validation ในคอลัมน์ D |

`Index.html` มี `AUTO_REFRESH_MS` สำหรับปรับรอบการรีเฟรชอัตโนมัติ

## ทดลองหน้าเว็บโดยไม่ต้อง deploy

เปิดไฟล์ `Index.html` ในเบราว์เซอร์ได้โดยตรง ระบบจะเข้า **โหมดตัวอย่าง** ใช้ข้อมูลจำลอง (ไม่เชื่อมต่อชีต)
