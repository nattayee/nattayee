# ระบบเช็กอินเจ้าหน้าที่แต่ละโซน (สแกน QR Code)

เว็บแอปสำหรับเช็กอินเจ้าหน้าที่ (อยู่ / ไม่อยู่ / บาดเจ็บ) และเก็บเบอร์โทร วันเกิด ตามโซน
ดึงรายชื่อและบันทึกผลลง Google Sheet
[รายชื่อเจ้าหน้าที่แต่ละโซน](https://docs.google.com/spreadsheets/d/1-6yW-yDd3l6LDmkJUliJyPGggXpLm3edwrXDXZ7LxFM/edit) โดยตรง
สร้างด้วย Google Apps Script จึงไม่ต้องมีเซิร์ฟเวอร์

## ภาพรวมการใช้งาน

```
พิมพ์ QR Code ติดแต่ละโซน ──▶ เจ้าหน้าที่สแกนด้วยมือถือ ──▶ ค้นหาชื่อตัวเอง
     (?page=qr)                                            │
                                                          ▼
ผู้ดูแลดูผลแบบเรียลไทม์ ◀── บันทึกลง Google Sheet ◀── เลือกสถานะ + กรอกเบอร์โทร/วันเกิด
     (?page=admin)
```

| หน้า | ลิงก์ | ใครใช้ |
| --- | --- | --- |
| เช็กอินด้วยตนเอง | `…/exec` หรือ `…/exec?z=<รหัสโซน>` (จาก QR Code) | เจ้าหน้าที่ทุกคน |
| พิมพ์ QR Code | `…/exec?page=qr` | ผู้ดูแล |
| แดชบอร์ด | `…/exec?page=admin` (ต้องใส่รหัสผู้ดูแล) | ผู้ดูแล / ผู้บัญชาการเหตุการณ์ |

## ความสามารถ

### หน้าเช็กอินด้วยตนเอง (`Checkin.html`)
- สแกน QR Code ของโซน แล้วระบบแสดงรายชื่อในโซนนั้นตามหน่วยงานให้ทันที หรือพิมพ์ค้นหาชื่อ/นามสกุล
  (ค้นหาทุกโซนได้ ถ้าสแกนผิดโซน)
- เลือกสถานะ **อยู่ / ไม่อยู่ / บาดเจ็บ** (ต้องเลือก)
- กรอก **เบอร์โทร** และ **วันเกิด (พ.ศ.)** บังคับกรอกหากยังไม่มีในชีต ถ้ามีแล้วเว้นว่างได้ (ข้อมูลเดิมไม่ถูกลบ)
- เลือก "บาดเจ็บ" ช่องหมายเหตุจะเปลี่ยนเป็น "อาการบาดเจ็บ / จุดที่อยู่ตอนนี้"
- จำชื่อบนมือถือเครื่องนั้น สแกนครั้งต่อไปกด "ใช่ ฉันเอง" ได้เลย และมีปุ่ม "เช็กอินให้คนอื่น"
- **ไม่แสดงเบอร์โทร วันเกิด หรือหมายเหตุของใคร** หน้าเช็กอินได้แค่ชื่อ ตำแหน่ง หน่วยงาน และว่าเช็กอินแล้วหรือยัง

### หน้าพิมพ์ QR Code (`Qr.html`)
- สร้าง QR Code ของทุกโซนอัตโนมัติจากแท็บในชีต และ QR "ทุกโซน" อีก 1 อัน
- พิมพ์แบบ **1 โซนต่อหน้า A4** (ติดผนังจุดรวมพล) หรือ **4 โซนต่อหน้า** หรือบันทึกเป็น PDF
- QR ใช้รหัสแท็บ (`?z=…`) แทนชื่อโซน ลิงก์จึงสั้น สแกนง่าย และยังใช้ได้แม้เปลี่ยนชื่อแท็บ
- แก้ลิงก์เป็นลิงก์ย่อได้ (เช่น bit.ly ที่ชี้ไปยังเว็บแอปเดียวกัน)
- ไลบรารีสร้าง QR ฝังอยู่ในไฟล์ ไม่ต้องโหลดจากอินเทอร์เน็ตภายนอก

### แดชบอร์ดผู้ดูแล (`Admin.html`)
- สรุป **ทั้งหมด / อยู่ / ไม่อยู่ / บาดเจ็บ / ไม่ทราบ** ภาพรวมและรายโซน กดตัวเลขเพื่อกรอง
- คนบาดเจ็บไฮไลต์สีแดง แท็บโซนแสดงจำนวนคนบาดเจ็บ
- เปลี่ยนสถานะด้วยปุ่มลัด หรือ **✎ ข้อมูล** เพื่อแก้เบอร์โทร วันเกิด หมายเหตุ ให้คนที่ไม่มีมือถือ
- ปุ่ม **ข้อมูลไม่ครบ** แสดงคนที่ยังไม่มีเบอร์โทรหรือวันเกิด
- รีเฟรชอัตโนมัติทุก 20 วินาที เห็นคนที่สแกนเช็กอินเข้ามาแบบเรียลไทม์
- ปุ่มรีเซ็ตสถานะกลับเป็น "ไม่ทราบ" สำหรับการซ้อมครั้งถัดไป (เก็บเบอร์โทรและวันเกิดไว้)
- ต้องใส่ **รหัสผู้ดูแล** (`ADMIN_PIN`) ก่อนเข้า

## โครงสร้างชีตที่รองรับ

ระบบจะใช้ทุกแท็บที่มี `D2 = สถานะ` และ `E2 = ชื่อ-สกุล` (ตอนนี้คือ โซนที่ 1 – โซน8 รวม 410 คน)

| คอลัมน์ | ข้อมูล |
| --- | --- |
| A (merge A:F) | ชื่อหน่วยงาน (แถวที่ 1 และแถวคั่นหน่วยงาน) |
| D | สถานะ: อยู่ / ไม่อยู่ / บาดเจ็บ / ไม่ทราบ (ไม่ทราบ = ยังไม่เช็กอิน) |
| E | ชื่อ-สกุล (ถ้าขึ้นต้นด้วย `-` จะแสดงเป็นหมายเหตุ เช่น "- เช็ครายชื่อที่โซน 2 -") |
| F | ตำแหน่ง |
| G | เบอร์โทร (ระบบเขียนให้) |
| H | วันเกิด (ระบบเขียนให้ ถ้ากรอกเองเป็นข้อความ เช่น 15/03/2530 ก็อ่านได้) |
| I | อัปเดตล่าสุด (ระบบเขียนให้) |
| J | หมายเหตุ (ระบบเขียนให้) |

**เรื่องดรอปดาวน์สถานะเดิม:** คอลัมน์ D เดิมมีดรอปดาวน์ อยู่/ลา/ไม่ทราบ เมื่อบันทึกครั้งแรกในแต่ละแท็บ
ระบบจะเปลี่ยนดรอปดาวน์ของแถวเจ้าหน้าที่เป็น อยู่/ไม่อยู่/บาดเจ็บ/ไม่ทราบ ให้อัตโนมัติ
ค่า "ลา" ที่มีอยู่เดิมจะแสดงเป็น "ไม่อยู่" (หัวตาราง A2:C2 เดิมไม่ได้ใช้งาน แก้ไขเองได้ตามต้องการ)

เพิ่ม/ลบ/ย้ายรายชื่อหรือเพิ่มแท็บโซนใหม่ในชีตได้ตามปกติ ระบบอ่านใหม่ทุกครั้ง
(เพิ่มโซนใหม่แล้วต้องพิมพ์ QR ของโซนนั้นเพิ่ม) ก่อนบันทึกจะตรวจชื่อในแถวก่อนเสมอ
ถ้าแถวเลื่อนไปจะค้นหาชื่อในแท็บเดิมให้อัตโนมัติ

## วิธีติดตั้ง (ประมาณ 10 นาที)

1. เปิด Google Sheet แล้วไปที่เมนู **ส่วนขยาย → Apps Script**
2. ในไฟล์ `Code.gs` ลบโค้ดเดิมทั้งหมด แล้ววางเนื้อหาจาก [`Code.gs`](./Code.gs)
3. **ตั้งรหัสผู้ดูแล** ใน `Code.gs` บรรทัด `var ADMIN_PIN = '';` เช่น `var ADMIN_PIN = '58204917';`
   (ควรยาวอย่างน้อย 6 หลัก และไม่ใช่เลขที่เดาง่าย)
4. สร้างไฟล์ HTML 3 ไฟล์ (กด **+** ข้างคำว่า "ไฟล์" → **HTML** แล้วตั้งชื่อ **ตรงตามนี้ ไม่ต้องใส่ .html**)
   วางเนื้อหาจากไฟล์ที่ชื่อเดียวกัน
   - `Checkin` ← [`Checkin.html`](./Checkin.html)
   - `Admin` ← [`Admin.html`](./Admin.html)
   - `Qr` ← [`Qr.html`](./Qr.html)
   - ถ้าเคยติดตั้งเวอร์ชันก่อนหน้า ให้ **ลบไฟล์ `Index`** ทิ้ง
5. (แนะนำ) ไปที่ ⚙️ **การตั้งค่าโปรเจ็กต์** ตั้งเขตเวลาเป็น `(GMT+07:00) Bangkok`
6. กด **บันทึก** แล้วกด **ทำให้ใช้งานได้ (Deploy) → การทำให้ใช้งานได้รายการใหม่**
   - ประเภท: **เว็บแอป**
   - เรียกใช้ในฐานะ: **ฉัน** (บัญชีเจ้าของชีต)
   - ผู้ที่มีสิทธิ์เข้าถึง: **ทุกคน** หากต้องการให้สแกนแล้วใช้ได้ทันทีโดยไม่ต้องล็อกอิน
     (ดูหัวข้อความปลอดภัยด้านล่าง)
7. กด **ทำให้ใช้งานได้** แล้วอนุญาตสิทธิ์เข้าถึงชีต (ครั้งแรกอาจเจอหน้า "Google ยังไม่ได้ยืนยันแอปนี้" ให้กด
   **ขั้นสูง → ไปที่ … (ไม่ปลอดภัย)** เพราะเป็นสคริปต์ของเราเอง)
8. คัดลอก **URL ของเว็บแอป** (ลงท้ายด้วย `/exec`) แล้วเปิด `URL?page=qr` เพื่อพิมพ์ QR Code ติดแต่ละโซน
9. ทดลองสแกน QR ด้วยมือถือ 1 เครื่องก่อนติดจริง แล้วเปิด `URL?page=admin` ดูผล

> แก้โค้ดภายหลัง: ต้องไปที่ **ทำให้ใช้งานได้ → จัดการการทำให้ใช้งานได้ → แก้ไข (✏️) → เวอร์ชัน: เวอร์ชันใหม่**
> URL เดิม (และ QR Code ที่พิมพ์ไว้) จึงจะได้โค้ดใหม่ **อย่าสร้าง Deploy รายการใหม่** เพราะ URL จะเปลี่ยนและ QR เดิมจะใช้ไม่ได้

### ทางเลือก: ติดตั้งด้วย clasp

```bash
npm install -g @google/clasp
clasp login
clasp create --type standalone --title "ระบบเช็กอินเจ้าหน้าที่" --rootDir checkin
clasp push
clasp deploy
```

(`Code.gs` เปิดชีตด้วย `SPREADSHEET_ID` จึงใช้เป็นโปรเจ็กต์แบบ standalone ได้)

## ความปลอดภัย

เว็บแอปทำงานด้วยสิทธิ์ของผู้ deploy และลิงก์ถูกแจกผ่าน QR Code จึงควรรู้ว่าใครทำอะไรได้

- **หน้าเช็กอิน (ทุกคนที่มีลิงก์):** เห็นรายชื่อ ตำแหน่ง หน่วยงาน และบันทึกสถานะ/เบอร์โทร/วันเกิดได้
  แต่ **อ่าน** เบอร์โทร วันเกิด หรือหมายเหตุของคนอื่นไม่ได้
  ข้อจำกัด: คนที่มีลิงก์สามารถเช็กอินแทนชื่ออื่นได้ (เหมือนการเซ็นชื่อแทนบนกระดาษ) ผู้ดูแลแก้ไขได้ที่แดชบอร์ด
- **แดชบอร์ดและการรีเซ็ต:** ต้องใช้ `ADMIN_PIN` หากไม่ได้ตั้ง แดชบอร์ดจะแสดงคำเตือนสีแดง
- **ผู้ที่มีสิทธิ์เข้าถึง (ตอน Deploy):**
  - **ทุกคน:** สแกนแล้วใช้ได้ทันที สะดวกที่สุดสำหรับเหตุฉุกเฉิน/การซ้อม
  - **ทุกคนที่มีบัญชี Google / ทุกคนในองค์กร:** ปลอดภัยขึ้น แต่ต้องล็อกอินก่อนเช็กอิน
- ชีตต้นฉบับไม่จำเป็นต้องแชร์ให้ผู้ใช้เว็บ

## การตั้งค่าใน `Code.gs`

| ค่า | ความหมาย |
| --- | --- |
| `SPREADSHEET_ID` | ID ของ Google Sheet |
| `ADMIN_PIN` | รหัสผู้ดูแลสำหรับแดชบอร์ด (ว่าง = ไม่ต้องใช้รหัส ไม่แนะนำ) |
| `COL_PHONE`, `COL_BIRTHDAY`, `COL_UPDATED`, `COL_NOTE` | คอลัมน์ที่ใช้เก็บข้อมูล (ค่าเริ่มต้น G, H, I, J) |
| `STATUSES` / `CHECKIN_STATUSES` | สถานะทั้งหมด / สถานะที่เจ้าหน้าที่เลือกเองได้ |
| `LEGACY_STATUS` | ค่าสถานะเดิมที่แปลงเป็นค่าใหม่ เช่น ลา → ไม่อยู่ |

## ทดลองหน้าเว็บโดยไม่ต้อง deploy

เปิดไฟล์ HTML ในเบราว์เซอร์ได้โดยตรง ระบบจะเข้า **โหมดตัวอย่าง** ใช้ข้อมูลจำลอง (ไม่เชื่อมต่อชีต)
เช่น `Checkin.html?z=111` (จำลองการสแกน QR ของโซน 2), `Qr.html`, `Admin.html`
