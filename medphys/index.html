เข้าสู่ระบบ

ใช้ชื่อผู้ใช้และรหัสผ่านของ LPCH RO Workspace

ไปที่ LPCH RO Workspace

หรือเข้าสู่ระบบที่ LPCH RO Workspace แล้วกดปุ่มระบบนี้ จะเข้าได้ทันที · บันทึกข้อมูลได้เฉพาะนักฟิสิกส์การแพทย์ (MP) ตำแหน่งอื่นดูได้อย่างเดียว · ลืมรหัสผ่านให้รีเซ็ตที่ LPCH RO Workspace

ดูได้อย่างเดียว

ยังไม่มีแถบที่ดูได้แอดมินยังไม่ได้เปิดให้ตำแหน่งอื่นที่ไม่ใช่ MP ดูหน้าใด · แอดมินเลือกได้ที่ ตั้งค่า → แถบเมนู (ช่อง "ตำแหน่งอื่น")

ยังไม่ได้เชื่อมกับ LPCH RO Workspace

ลิงก์นี้ยังเปิด Code.gs รุ่นเก่า ซึ่งไม่มีการเข้าสู่ระบบด้วยชื่อผู้ใช้และรหัสผ่าน LPCH · ตรวจพบ:

  1. เปิด Google Sheet ของระบบ → ส่วนขยาย → Apps Script
  2. รายการไฟล์ด้านซ้ายต้องมีไฟล์ .gs ไฟล์เดียว (Code.gs) ถ้ามีไฟล์ .gs อื่นที่เป็นโค้ดเก่า ให้ลบออก
  3. ไฟล์ Code.gs: กด Ctrl/⌘ + A แล้ววาง Code.gs ใหม่ทับทั้งไฟล์ → กด บันทึก
  4. เลือกฟังก์ชัน checkSetup → เรียกใช้ → อนุญาตสิทธิ์ (ดูผลที่บันทึกการทำงาน)
  5. ปุ่ม การทำให้ใช้งานได้ (Deploy) → จัดการการทำให้ใช้งานได้ (Manage deployments) → กด ดินสอ (Edit) → ช่อง เวอร์ชัน (Version) เลือก เวอร์ชันใหม่ (New version) → ดำเนินการในฐานะ ฉัน (Me) · ผู้มีสิทธิ์ ทุกคน (Anyone) → ทำให้ใช้งานได้ (Deploy)
  6. ตรวจ: เติม ?ping=1 ท้ายลิงก์นี้ (…/exec?ping=1) ต้องเห็นข้อความที่มี "codeVersion" ถ้ายังเห็นหน้าระบบ แปลว่าลิงก์นี้ยังเป็นรุ่นเก่า
  7. เปิดลิงก์นี้อีกครั้ง จะเจอหน้าเข้าสู่ระบบด้วยชื่อผู้ใช้และรหัสผ่าน LPCH

ลิงก์ที่เปิดอยู่ต้องอยู่ในรายการ "จัดการการทำให้ใช้งานได้" ของโปรเจกต์ที่วางโค้ด ถ้าไม่อยู่ แปลว่าลิงก์นี้มาจากโปรเจกต์ Apps Script อื่น · ถ้าข้อ 5 เลือกเวอร์ชันเดิม หรือกด "การทำให้ใช้งานได้รายการใหม่" ลิงก์นี้จะยังเป็นรุ่นเก่า
