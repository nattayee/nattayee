# ระบบกระจายงานฟิสิกส์การแพทย์

กลุ่มงานรังสีรักษา โรงพยาบาลมะเร็งลำปาง

เว็บแอปหน้าเดียวสำหรับแจกเคสวางแผนการรักษาให้นักฟิสิกส์การแพทย์ตามคิวหมุนเวียน ติดตามงานค้าง บันทึก RC และสรุปแต้ม P4P รายเดือน
ทำตามโครงสร้างของไฟล์ `P4P_Physics` เดิม ข้อมูลเก็บใน Google Sheet ของทีมเอง

## ทำอะไรได้บ้าง

- **แจกเคสใหม่อัตโนมัติ**: กรอก HN รายละเอียดผู้ป่วย แล้วเลือกเทคนิค ระบบเลือก MP ให้เองก่อนกด "แจกเคส"
  พร้อมแสดงว่าเคสจะไปที่ใคร (ปุ่มเทคนิคแต่ละปุ่มบอกคนถัดไปไว้ด้วย) กด "เลิกทำ" ได้ถ้าแจกผิด
- **คิวหมุนเวียนแยกตามเทคนิค** ตามลำดับทีม JR → WM → NY → WS เหมือนคอลัมน์ MP ที่เติมไว้ล่วงหน้าในแต่ละแท็บ
  ใครได้เคสแล้ว เคสถัดไปของเทคนิคนั้นจะวนไปคนต่อไป
- **วันลา**: กด "ลาวันนี้" ที่การ์ดของแต่ละคน หรือ "จัดการวันลา" เพื่อลงวันลาล่วงหน้าเป็นช่วงวัน
  คนที่ลาในวัน In ของเคสจะไม่ได้รับเคส ระบบข้ามไปคนถัดไปและไม่ทำให้ใครได้เคสซ้ำสองครั้งติด
- **ติดตามงานค้าง**: เรียงตามวัน Sim พร้อมบอกว่าเหลืออีกกี่วันหรือเลยกำหนดมาแล้ว กดปุ่ม `Finish` หรือ `Evaluate` เพื่อลงวันที่เป็นวันนี้ทันที
- **RC (Quality Checklist)**: กด `+ RC` ที่เคส ระบบแนะนำคนที่ RC น้อยที่สุดเดือนนี้ (ไม่ใช่ผู้วางแผน) และบันทึก RC ที่ไม่ผูกกับเคสได้ เช่น RC Decay
- **กิจกรรมอื่น**: Daily QA, งานวิชาการ, งานบริหาร (เวลา × k)
- **สรุป P4P**: แต้มรายคนรายเดือน, แต้มต่อ, ส่วนต่างจากแต้มประกัน 1,200 และสถิติเคสตาม Type / Aim แบบเดียวกับแท็บ Month
- **นำเข้าข้อมูลจากไฟล์เดิม**: อ่านแท็บ 3D, 3D Bt, VM bt, VM etc, VM Chest, VM H&N, VM Brain, SRS CSI, Brachy, Hyper, RC, วิชาการ
  และแต้มต่อในแท็บ P4P โดยไม่แก้ไขแท็บเดิม

## การคิดแต้ม (ตรงกับสูตรในแท็บ P4P)

```
แต้มต่อหน่วย = เวลา (นาที) × น้ำหนักค่างาน × 0.143
แต้มที่ทำได้ = Σ(จำนวน × แต้มต่อหน่วย) + งานวิชาการ/บริหาร (เวลา × k × 0.143) + แต้มต่อ
ส่วนต่างแต้ม = แต้มที่ทำได้ − 1,200
```

- เคสนับให้ **MP** ตาม **วัน In** และเคสในหมวดวางแผน (3D, VMAT, SRS) ได้ **New MU** เพิ่มอีก 1 ครั้ง
- RC นับเป็น Quality Checklist ให้คนที่ RC ตามวันที่บันทึก
- เวลาและน้ำหนักของทุกหมวดแก้ได้ในหน้า **ตั้งค่า**

## กติกาคิว

1. เคสใหม่ของเทคนิคหนึ่งไปที่คนถัดจากคนที่ได้เคสล่าสุดของเทคนิคนั้น ตามลำดับในหน้าตั้งค่า
2. ถ้าคนนั้นลาในวัน In ของเคส หรือปิด "ปฏิบัติงาน" ไว้ ระบบข้ามไปคนถัดไป
3. Brachy และ Hyperthermia ใช้คิว **รายวัน** คือเคสวันเดียวกันไปที่คนเดิม วันใหม่จึงวนไปคนถัดไป (เปลี่ยนเป็นทุกเคสได้ในหน้าตั้งค่า)
4. ตั้งคนถัดไปของแต่ละเทคนิคเองได้ในหน้าตั้งค่า (เหมือนเว้นแถวหรือสลับชื่อในไฟล์เดิม)
5. บน Google Sheet ระบบเลือกคนรับเคสฝั่งเซิร์ฟเวอร์ภายใต้ล็อก ถ้าสองคนกดแจกเคสพร้อมกันก็จะไม่ได้คนเดียวกัน

ทดสอบโดยนำเข้าข้อมูลเดือนตุลาคม 2569 จากไฟล์เดิมแล้ว แต้มที่ทำได้ของทุกคนตรงกับแท็บ P4P ถึงทศนิยมตำแหน่งที่ 3

## ติดตั้งกับ Google Sheet

1. เปิดไฟล์ `P4P_Physics` ใน Google Sheets (หรือสำเนาของไฟล์)
2. เมนู **ส่วนขยาย → Apps Script**
3. ในไฟล์ `Code.gs` ให้ลบโค้ดเดิมแล้ววางเนื้อหาจาก [`Code.gs`](Code.gs)
4. กด **＋ → HTML** ตั้งชื่อไฟล์ว่า `index` แล้ววางเนื้อหาจาก [`index.html`](index.html)
5. กดบันทึก แล้วกลับไปที่ชีตและรีเฟรชหน้า จะมีเมนู **ระบบกระจายงาน** เพิ่มขึ้น
6. เลือก **ระบบกระจายงาน → นำเข้าข้อมูลจากแท็บเดิม** (ครั้งแรก Google จะขอสิทธิ์ ให้กดอนุญาต)
   ระบบจะสร้างแท็บ `Cases`, `Logs`, `Leaves`, `Config` และตั้งคิวถัดไปให้ตรงกับแถวว่างในแท็บเดิม รันซ้ำได้โดยไม่เพิ่มรายการซ้ำ
7. ใช้งานได้สองแบบ
   - **ในชีต**: ระบบกระจายงาน → เปิดระบบ
   - **เป็นเว็บ (ใช้บนมือถือได้)**: ใน Apps Script กด **การทำให้ใช้งานได้ → การทำให้ใช้งานได้รายการใหม่ → เว็บแอป**
     - ดำเนินการในฐานะ: **ผู้ใช้ที่เข้าถึงเว็บแอป**
     - ผู้ที่มีสิทธิ์เข้าถึง: **ทุกคนที่มีบัญชี Google**
     - คัดลอก URL ไปบุ๊กมาร์กหรือแชร์ในกลุ่ม
8. แชร์ไฟล์ชีตให้ทีมแบบ **ผู้แก้ไข** เฉพาะคนที่มีสิทธิ์แก้ไขชีตเท่านั้นจึงจะเปิดดูและบันทึกข้อมูลได้

เมื่อแก้โค้ดภายหลัง ให้กด **จัดการการทำให้ใช้งานได้ → แก้ไข → เวอร์ชันใหม่** เพื่อให้ URL เดิมใช้โค้ดใหม่

## ลองใช้โดยไม่ต้องติดตั้ง

เปิด `index.html` ในเบราว์เซอร์ได้เลย ระบบจะเข้าโหมดตัวอย่างพร้อมเคสสมมติ (HN ขึ้นต้นด้วย 999)
ข้อมูลในโหมดนี้เก็บไว้ในเบราว์เซอร์เครื่องนั้นเท่านั้น

## โครงสร้างข้อมูลในชีต

| แท็บ | เนื้อหา |
| --- | --- |
| `Cases` | id, หมวด, MP, CT-Sim, In, Sim, Finish, Evaluate, Type, HN, Name, Doc, Aim, Technique, Note |
| `Logs` | id, ประเภท (`rc` / `dqa` / `acad` / `admin`), Date, MP, HN, Name, เคส (id), กิจกรรม, เวลา, k, Note |
| `Leaves` | id, MP, ตั้งแต่, ถึง, Note |
| `Config` | ทีม, คนถัดไปที่ตั้งเอง, เวลาและน้ำหนักของแต่ละหมวด, แต้มต่อรายเดือน (JSON) |

ข้อมูลทั้งหมดเป็นข้อความล้วน เพิ่มคอลัมน์ของตัวเองต่อท้ายได้ ระบบจะไม่เขียนทับ

## ความเป็นส่วนตัว

ข้อมูลผู้ป่วย (HN, ชื่อ) อยู่ใน Google Sheet ของโรงพยาบาลเท่านั้น โค้ดในโฟลเดอร์นี้ไม่มีข้อมูลผู้ป่วยจริง
