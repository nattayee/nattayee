# ระบบกระจายงาน ฟิสิกส์การแพทย์
**กลุ่มงานรังสีรักษา โรงพยาบาลมะเร็งลำปาง**

เว็บแอปสำหรับกระจายงานวางแผนการรักษา ตรวจแผน และงาน QA ให้นักฟิสิกส์การแพทย์อย่างเป็นธรรม
ระบบเลือกผู้รับงานจาก **ภาระงานสะสม** และ **ไม่ส่งงานให้คนที่ลา** โดยอัตโนมัติ
ใช้งานได้ทั้งบนคอมพิวเตอร์และมือถือ รองรับธีมสว่าง/มืด

| ไฟล์ | หน้าที่ |
|---|---|
| `index.html` | ตัวแอปทั้งหมด (ไฟล์เดียว ไม่ต้องติดตั้งอะไรเพิ่ม) |
| `apps-script/Code.gs` | ส่วนหลังบ้านบน Google Apps Script สำหรับใช้ข้อมูลร่วมกันทั้งทีมผ่าน Google Sheets |

---

## ความสามารถหลัก

### 1. กระจายงานอัตโนมัติ
- เลือกประเภทงาน (3D-CRT, IMRT, VMAT, SRS/SBRT, Brachytherapy, Re-plan, 2D/Electron, Patient QA, Daily/Monthly QA ฯลฯ) แล้วกรอก HN
- ระบบแสดง **ลำดับคิว** ว่าใครจะได้งานและเพราะอะไร ก่อนกดยืนยัน
- เลือก **ผู้ตรวจสอบแผน (second check)** ให้อัตโนมัติ (ต้องเป็นคนละคนกับผู้วางแผน และมีสิทธิ์ตรวจแผน)
- จะเลือกเองก็ได้ โดยแตะชื่อในคิว หรือสลับเป็นโหมด “เลือกเอง”
- กำหนดเสร็จคำนวณจากจำนวน **วันทำการ** ของแต่ละประเภทงาน (ข้ามเสาร์-อาทิตย์และวันหยุดราชการ)

### 2. วันลา: คนที่ลาจะไม่ได้รับงาน
- บันทึกวันลาได้ 5 ประเภท: ลาพักผ่อน ลาป่วย ลากิจ ไปราชการ/อบรม/ประชุม และอื่น ๆ (ลาเต็มวัน หรือครึ่งวันเช้า/บ่าย)
- **ปฏิทินวันลารายเดือน**: คลิกช่องเพื่อบันทึก หรือลากเมาส์ข้ามหลายวันเพื่อเลือกเป็นช่วง แถวล่างสุดแสดงจำนวนคนที่พร้อมรับงานในแต่ละวัน
- คนที่ลาจะถูก **ข้ามในการกระจายงานอัตโนมัติ** และ **เลือกเองไม่ได้** (ตัวเลือกจะเป็นสีเทาพร้อมเหตุผล)
- ค่าเริ่มต้นจะตรวจวันลา **ตั้งแต่วันรับงานจนถึงวันกำหนดเสร็จ** เช่น งาน VMAT ที่ต้องเสร็จใน 3 วัน จะไม่ส่งให้คนที่จะลาวันพรุ่งนี้
- ถ้าบันทึกวันลาภายหลัง (เช่น ลาป่วยกะทันหัน) แล้วมีงานค้างในช่วงนั้น ระบบจะ **เตือนและเสนอผู้รับงานคนใหม่** ให้กดกระจายใหม่ได้ทันที

### 3. ความเป็นธรรมของภาระงาน
- งานแต่ละประเภทมี **แต้มภาระงาน** (ปรับได้) เช่น 3D-CRT = 1, IMRT/VMAT = 2, SRS/SBRT = 3 และผู้ตรวจแผนได้แต้มตรวจแผน
- คิวเรียงตามแต้มย้อนหลัง 30 วัน (ปรับได้) **เทียบกับจำนวนวันที่มาทำงานจริง** คนที่เพิ่งกลับจากลาจึงไม่ถูกเทงานสะสมให้ทีเดียว
- กำหนด **สัดส่วนการรับงาน** รายคนได้ (เช่น หัวหน้างาน 50–60%)
- กำหนดได้ว่าใคร **ไม่รับงานประเภทใด** (เช่น ผู้ที่ยังไม่ผ่านการฝึก SRS) และใคร **ตรวจแผนได้**

### 4. จัดเวรเป็นช่วงวันที่
สร้างงานประจำ (เช่น Daily QA) ทุกวันทำการในช่วงที่เลือก แล้วหมุนเวียนผู้รับผิดชอบให้เท่า ๆ กัน โดยข้ามวันหยุดและคนที่ลา พร้อมตัวอย่างก่อนยืนยัน

### 5. ติดตามและรายงาน
- หน้า **ภาพรวม**: งานวันนี้ งานค้าง งานเกินกำหนด คนที่พร้อมรับงาน กราฟภาระงาน และวันลาที่จะถึง
- หน้า **รายการงาน**: ค้นหา/กรองตามเดือน คน ประเภท สถานะ เปลี่ยนสถานะได้ในตาราง แก้ไขหรือเปลี่ยนผู้รับผิดชอบ (มีประวัติการเปลี่ยน)
- **สรุปภาระงานรายเดือน** แยกตามคนและประเภทงาน สำหรับรายงานผลการปฏิบัติงาน
- ส่งออก Excel (CSV) พิมพ์ได้ และสำรอง/นำเข้าข้อมูล (JSON)

## วิธีใช้งาน

### แบบที่ 1: ลองใช้ทันที (เก็บข้อมูลในเบราว์เซอร์)
เปิดไฟล์ `index.html` ด้วย Chrome / Edge / Safari ได้เลย
ข้อมูลจะเก็บในเบราว์เซอร์เครื่องนั้นเท่านั้น เหมาะสำหรับทดลอง หรือใช้เครื่องเดียวในห้องฟิสิกส์
(ควรกด “สำรองข้อมูล” ที่หน้าตั้งค่าเป็นระยะ)

### แบบที่ 2: ใช้ร่วมกันทั้งทีมผ่าน Google Sheets (แนะนำ)
ข้อมูลเก็บใน Google Sheet ทุกคนเห็นข้อมูลชุดเดียวกัน และหน้าเว็บอัปเดตเองทุก 30 วินาที

1. เปิด Google Sheet ที่จะใช้เก็บข้อมูล (ใช้ไฟล์เดิมของทีม หรือสร้างใหม่ก็ได้)
2. เมนู **ส่วนขยาย → Apps Script**
3. ในไฟล์ `Code.gs` ลบโค้ดเดิม แล้ววางเนื้อหาจาก `apps-script/Code.gs`
4. กด **＋ → HTML** ตั้งชื่อไฟล์ว่า `index` (ไม่ต้องพิมพ์ .html) แล้ววางเนื้อหาทั้งหมดจาก `index.html`
5. กด **บันทึก** → **การทำให้ใช้งานได้ (Deploy) → การทำให้ใช้งานได้รายการใหม่**
   - ประเภท: **เว็บแอป**
   - เรียกใช้ในฐานะ: **ฉัน**
   - ผู้ที่มีสิทธิ์เข้าถึง: **ทุกคนในองค์กร** หรือ **ทุกคนที่มีบัญชี Google** (แล้วแชร์ลิงก์เฉพาะในทีม)
6. อนุญาตสิทธิ์ตามที่ระบบถาม แล้วเปิด **URL ของเว็บแอป** ที่ได้ → บันทึกเป็นบุ๊กมาร์ก/เพิ่มลงหน้าจอโฮมมือถือ

ครั้งแรกระบบจะสร้างข้อมูลตัวอย่าง ให้แก้รายชื่อที่เมนู **บุคลากร** แล้วกด **ล้างข้อมูลตัวอย่าง**

ใน Google Sheet จะมีชีตเพิ่มขึ้นมา:
- `_appdata` (ซ่อนไว้): ที่เก็บข้อมูลของระบบ **ห้ามแก้ไขด้วยมือ**
- `งาน`, `วันลา`, `บุคลากร`: อัปเดตอัตโนมัติทุกครั้งที่บันทึก ใช้เปิดดู กรอง หรือทำรายงานต่อใน Sheets ได้ (การแก้ในชีตเหล่านี้จะไม่ย้อนกลับเข้าระบบ)

> ถ้าต้องการให้ Apps Script ใช้ Google Sheet ไฟล์อื่น (ไม่ใช่ไฟล์ที่ผูกอยู่) ให้ตั้งค่า Script Property ชื่อ `SPREADSHEET_ID` เป็นรหัสของไฟล์นั้น
>
> เมื่อแก้ไข `index.html` หรือ `Code.gs` ภายหลัง ให้ Deploy → **จัดการการทำให้ใช้งานได้ → แก้ไข → เวอร์ชันใหม่** เพื่อให้ URL เดิมใช้โค้ดใหม่

**กรณีหลายคนแก้ไขพร้อมกัน:** ระบบตรวจเวอร์ชันข้อมูลทุกครั้งที่บันทึก ถ้ามีคนอื่นบันทึกก่อน จะดึงข้อมูลล่าสุดแล้วทำรายการของเราซ้ำให้อัตโนมัติ ข้อมูลของทั้งสองฝั่งจึงไม่หาย

## เริ่มใช้งานจริง (ครั้งแรก)
1. **บุคลากร** → แก้ไขชื่อ ตำแหน่ง ประเภทงานที่รับ สิทธิ์ตรวจแผน และสัดส่วนการรับงานของแต่ละคน
2. **ตั้งค่า → ประเภทงาน** → ปรับชื่อ แต้ม และจำนวนวันทำการให้ตรงกับงานจริงของหน่วยงาน
3. **ตั้งค่า → วันหยุดราชการ** → ตรวจสอบและเพิ่มวันหยุดทางจันทรคติ/วันหยุดชดเชยตามประกาศของปีนั้น (ระบบใส่ให้เฉพาะวันหยุดที่วันที่คงที่)
4. **ตั้งค่า → ล้างงานและวันลาทั้งหมด** เพื่อลบข้อมูลตัวอย่าง
5. **วันลา** → บันทึกวันลาที่ทราบล่วงหน้าของทุกคน
6. เริ่มกระจายงานที่เมนู **กระจายงาน**

## หลักการเลือกผู้รับงาน (สำหรับอธิบายทีม)
1. ตัดคนที่ **ปิดรับงาน / ไม่รับงานประเภทนี้ / ไม่มีสิทธิ์ตรวจแผน (กรณีเลือกผู้ตรวจ) / ลา** ในช่วงวันรับงานถึงกำหนดเสร็จ
2. คำนวณ **คะแนนภาระงาน** = แต้มงานย้อนหลัง N วัน ÷ จำนวนวันที่มาทำงานในช่วงนั้น ÷ สัดส่วนการรับงาน
3. ผู้ที่คะแนนต่ำสุดได้งาน ถ้าเท่ากันจะดูจำนวนงานค้าง แล้วดูว่าใครได้งานล่าสุดนานกว่า
4. ในการจัดเวร (โหมดหมุนเวียน) จะนับจำนวนเวรประเภทนั้นก่อน แล้วจึงดูคะแนนภาระงาน

## ความเป็นส่วนตัวของข้อมูลผู้ป่วย
ช่องชื่อผู้ป่วยไม่บังคับกรอก แนะนำให้ใช้ HN หรืออักษรย่อ และจำกัดสิทธิ์เข้าถึงเว็บแอปและ Google Sheet ให้เฉพาะบุคลากรในหน่วยงาน
