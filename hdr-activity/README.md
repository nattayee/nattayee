# HDR Activity

งานฟิสิกส์การแพทย์ กลุ่มงานรังสีรักษา โรงพยาบาลมะเร็งลำปาง

เว็บแอปสำหรับบันทึกค่า activity ของแหล่งกำเนิดรังสี HDR ที่วัดได้ในแต่ละวัน แอปจะเทียบกับค่าที่คำนวณจากการสลายตัว แล้วแสดงกราฟและ % ความต่าง

## วิธีใช้งาน

เปิดไฟล์ `index.html` ด้วยเบราว์เซอร์ได้ทันที ไม่ต้องติดตั้งอะไรเพิ่ม (ต้องต่ออินเทอร์เน็ตเพื่อโหลด Chart.js และฟอนต์)
หรือจะวางทั้งโฟลเดอร์ไว้บน web server หรือ GitHub Pages ก็ได้

1. **แหล่งกำเนิดรังสี & ตั้งค่า**: เพิ่ม source โดยกรอก serial, activity อ้างอิงจากใบรับรอง และวันที่/เวลาอ้างอิง
   ทุกครั้งที่เปลี่ยน source ให้เพิ่ม source ใหม่ ระบบจะเลือก source ที่ใช้งานอยู่ ณ วันที่วัดให้เอง
   ในหน้านี้ยังตั้งไอโซโทป (Ir-192 / Co-60 / กำหนดเอง), หน่วย, เกณฑ์ยอมรับ (ค่าเริ่มต้น ±5%) และรูปแบบปี พ.ศ./ค.ศ. ได้ด้วย
2. **ภาพรวม & บันทึกค่า**: กรอกวันที่/เวลาและค่า activity ที่วัดได้ แอปจะแสดงค่าคำนวณและ % ความต่างทันทีก่อนกดบันทึก
   - กราฟ 1: activity ที่คำนวณได้ (เส้น) เทียบกับค่าที่วัดได้ (จุด)
   - กราฟ 2: % ความต่าง พร้อมเส้นเกณฑ์ ±% (ค่าที่เกินเกณฑ์แสดงเป็น ▲ สีแดง)
   - เลือกช่วงเวลาได้ 30 วัน / 90 วัน / 1 ปี / ทั้งหมด และกรองตาม source ได้
3. **ตารางข้อมูล**: ดู แก้ไข และลบรายการ รวมทั้งส่งออกเป็น CSV
4. **นำเข้า / ส่งออก**:
   - ดึงข้อมูลจาก Google Sheets (ชีตต้องแชร์แบบ “ทุกคนที่มีลิงก์ดูได้”) แล้วจับคู่คอลัมน์วันที่ / เวลา / ค่าที่วัด / ค่าคำนวณ / หมายเหตุ ก่อนนำเข้า
     โดยค่าเริ่มต้นจะใส่ลิงก์ชีตตัวอย่างไว้ให้แล้ว
   - นำเข้าจากไฟล์ CSV หรือคัดลอกข้อมูลจากชีตมาวางก็ได้
   - สำรองข้อมูลและกู้คืนด้วยไฟล์ JSON

## การคำนวณ

```
A(t)    = A₀ · exp(−ln2 · Δt / T½)          Δt = เวลาวัด − เวลาอ้างอิงของ source (วัน)
% ต่าง  = (A_วัดได้ − A_คำนวณ) / A_คำนวณ × 100
```

ค่าเริ่มต้นของ T½ สำหรับ Ir-192 คือ 73.83 วัน
ถ้ากรอก “Activity คำนวณ” เองในรายการใด (หรือนำเข้ามาจากชีต) แอปจะใช้ค่านั้นแทนค่าที่คำนวณจาก source

## การรองรับรูปแบบวันที่ในชีต

- `12/10/2569`, `12/10/2026`, `12-10-69` (เลือกได้ว่าเป็น วัน/เดือน/ปี หรือ เดือน/วัน/ปี)
- `2026-10-12`, `12 ต.ค. 2569`, `12 ตุลาคม 2569`, `12 Oct 2026`, `Oct 12, 2026`
- ปี พ.ศ. จะแปลงเป็น ค.ศ. ให้อัตโนมัติ และรองรับเวลาทั้งในคอลัมน์เดียวกันหรือแยกคอลัมน์

## การเก็บข้อมูล

ข้อมูลจะเก็บไว้ใน `localStorage` ของเบราว์เซอร์เครื่องที่ใช้งานเท่านั้น ข้อมูลจะไม่แชร์ข้ามเครื่องหรือข้ามเบราว์เซอร์
ควรกด “ส่งออกไฟล์สำรอง (JSON)” เป็นระยะ และใช้ไฟล์นี้ย้ายข้อมูลไปยังเครื่องอื่น
