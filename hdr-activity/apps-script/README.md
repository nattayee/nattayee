# HDR Activity — Google Apps Script

เว็บแอปที่บันทึกค่า Planning ลงแท็บ **Record** ของชีต Brachy_therapy_Activity โดยตรง
แล้วแสดงกราฟ Calculation เทียบกับ Planning และ % ความต่าง

## ติดตั้ง

1. เปิดชีต → **ส่วนขยาย → Apps Script**
2. วาง `Code.gs` แทนโค้ดเดิม
3. เพิ่มไฟล์ HTML ชื่อ `index` แล้ววาง `index.html`
4. **ทำให้ใช้งานได้ → การทำให้ใช้งานได้รายการใหม่ → เว็บแอป**
   แนะนำ “ดำเนินการในฐานะ: ผู้ใช้ที่เข้าถึงเว็บแอป” และให้สิทธิ์แก้ไขชีตเฉพาะคนในทีม

## การทำงาน

- `getData()` อ่านแถวที่มีวันที่ในคอลัมน์ A และค่าคงที่ของ source จาก J2:K6
- `addRecord(date, planning, mp)` เขียนวันที่ (A), Planning (E) และ MP (F) ลงแถวว่างแรก
  ค่า Calculation (C), %Diff (D) และ t (G) มาจากสูตรเดิมในชีต ถ้าแถวนั้นยังไม่มีสูตร จะคัดลอกสูตรจากแถวก่อนหน้าให้
- ค่าตัวอย่างก่อนบันทึกใช้สูตรเดียวกับชีต: A = A0 · e^(−(0.693/T½)·t), %Diff = (Planning − A) / Planning × 100
