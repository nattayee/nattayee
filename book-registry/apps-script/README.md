# ทะเบียนหนังสือส่ง — เวอร์ชัน Google Apps Script

ใช้ Google Sheet ทะเบียนเดิมเป็นฐานข้อมูลโดยตรง (ชีตละปี พ.ศ.) ไม่ต้องมีเซิร์ฟเวอร์
เลขทะเบียนส่งรันต่อจากข้อมูลในชีต และยังเปิดดู/แก้ไขในชีตได้ตามปกติ

| ไฟล์ | ใส่ใน Apps Script เป็น |
| --- | --- |
| `Code.gs` | ไฟล์สคริปต์ `Code.gs` |
| `Index.html` | ไฟล์ HTML ชื่อ **`Index`** (ต้องสะกดตรงนี้) |

## ติดตั้ง

1. **นำไฟล์ Excel ขึ้น Google Sheets**
   อัปโหลดไฟล์ทะเบียน `.xlsx` ขึ้น Google Drive → เปิดด้วย Google ชีต → **ไฟล์ › บันทึกเป็น Google ชีต**
   - ชื่อชีตต้องเป็นปี พ.ศ. เช่น `2569`, `2568` และแถวแรกเป็นหัวตาราง
     `เลขทะเบียนส่ง | ที่ | ลงวันที่ | จาก | ถึง | เรื่อง | การปฏิบัติ | หมายเหตุ`
   - ตั้งเขตเวลา: **ไฟล์ › การตั้งค่า › เขตเวลา = (GMT+07:00) Bangkok**
2. **ใส่โค้ด**
   ในชีตนั้น เมนู **ส่วนขยาย › Apps Script**
   - ลบโค้ดเดิมใน `Code.gs` แล้ววางเนื้อหาจากไฟล์ `Code.gs`
   - กด **＋ › HTML** ตั้งชื่อ `Index` แล้ววางเนื้อหาจากไฟล์ `Index.html`
   - กด 💾 บันทึก
3. **เผยแพร่เป็นเว็บแอป**
   **ทำให้ใช้งานได้ (Deploy) › การทำให้ใช้งานได้รายการใหม่ › เลือกประเภท: เว็บแอป** แล้วเลือกการตั้งค่าตามตารางด้านล่าง
   → กด **ทำให้ใช้งานได้** → อนุญาตสิทธิ์ (ถ้าขึ้นว่าแอปยังไม่ผ่านการยืนยัน ให้กด *ขั้นสูง › ไปที่ … (ไม่ปลอดภัย)*)
   → คัดลอก **URL ของเว็บแอป** ไปใช้งาน/บุ๊กมาร์ก

| แบบ | ดำเนินการในฐานะ (Execute as) | ผู้ที่มีสิทธิ์เข้าถึง (Who has access) | หมายเหตุ |
| --- | --- | --- | --- |
| **ปลอดภัยกว่า (แนะนำ)** | ผู้ใช้ที่เข้าถึงเว็บแอป | ทุกคนที่มีบัญชี Google | ใช้ได้เฉพาะคนที่ถูกแชร์ชีตเป็น **ผู้แก้ไข** แต่ละคนต้องกดอนุญาตครั้งแรกครั้งเดียว |
| ง่ายกว่า | ฉัน (เจ้าของชีต) | ทุกคนที่มีบัญชี Google (หรือ *ทุกคนในองค์กร* ถ้าใช้ Google Workspace) | ใครมีลิงก์ก็ออกเลข/ดูทะเบียนได้ ควรส่งลิงก์ให้เฉพาะคนในหน่วยงาน |

### อัปเดตโค้ดภายหลัง

แก้โค้ดแล้วบันทึก → **ทำให้ใช้งานได้ › จัดการการทำให้ใช้งานได้ › ✏️ แก้ไข › เวอร์ชัน: เวอร์ชันใหม่ › ทำให้ใช้งานได้**
(URL เดิมใช้ต่อได้)

## การทำงาน

- **ออกเลขใหม่**: ได้เลขถัดไปของปี พ.ศ. ตามวันที่หนังสือ ระบบล็อกไม่ให้สองคนได้เลขซ้ำกัน
  - ถ้ามีแถวที่พิมพ์เลขรอไว้ (มีแต่เลข) จะเขียนลงแถวนั้น ไม่งั้นต่อท้ายชีต
  - ขึ้นปีใหม่ (เช่น 2570) ระบบสร้างชีตใหม่พร้อมหัวตารางไว้ด้านซ้ายสุดให้เอง
  - วันที่ถูกบันทึกเป็นเซลล์วันที่รูปแบบ `d/m/yyyy` (ในชีตแสดงเป็น ค.ศ. บนเว็บแสดงเป็น พ.ศ.)
  - ข้อความทุกช่องถูกเก็บเป็นข้อความล้วน (ไม่ถูกแปลงเป็นสูตรหรือวันที่)
- **เลขถัดไป** = ต่อจากเลขที่ออกล่าสุด ข้ามเลขที่มีอยู่แล้วในชีต
  ครั้งแรกจะเริ่มจากเลขว่างตัวแรกของปี (ไฟล์ปัจจุบัน: 2569 → 26 และข้าม 42–43 ที่มีอยู่แล้ว)
  ตั้งเองได้ที่ปุ่ม **ตั้งเลขถัดไปเอง** (ค่าเก็บใน *การตั้งค่าโปรเจ็กต์ › พร็อพเพอร์ตี้ของสคริปต์* ชื่อ `next_2569`)
- **ลบ**: ล้างข้อมูลในแถวแต่คงเลขไว้ในคอลัมน์แรก ลบเลขล่าสุดที่เพิ่งออก → ได้เลขนั้นคืน
- แถวที่ไม่มีเลขและมีแต่ข้อความในช่องเรื่อง ถือเป็นบรรทัดต่อของรายการก่อนหน้า
- พิมพ์/แก้ในชีตโดยตรงได้ กด **รีเฟรช** บนเว็บเพื่อโหลดข้อมูลล่าสุด

## ทดลองในเครื่องก่อน (ไม่บังคับ)

```
node scripts/preview-apps-script.js ทะเบียนหนังสือ.xlsx   # เปิด http://localhost:3200
npm test                                                  # รวมเทสต์ของ Code.gs ด้วย Google Sheet จำลอง
```
