# ทะเบียนหนังสือส่ง (เว็บ)

เว็บสำหรับออกเลขทะเบียนหนังสือส่ง ใช้รูปแบบเดียวกับไฟล์ Excel ทะเบียนเดิม
(ชีตละปี พ.ศ. คอลัมน์ `เลขทะเบียนส่ง · ที่ · ลงวันที่ · จาก · ถึง · เรื่อง · การปฏิบัติ · หมายเหตุ`)
และให้เลขทะเบียน **รันต่อจากไฟล์** ได้ทันที

- ออกเลขใหม่ได้ครั้งละหนึ่งเลข เลขไม่ซ้ำกันแม้หลายคนกดพร้อมกัน
- แยกเลขตามปี พ.ศ. ของวันที่หนังสือ (ขึ้นปีใหม่จะเริ่มที่เลข 1 เอง)
- ค้นหา กรองตามผู้ปฏิบัติ แก้ไข ลบ
- นำเข้า / ส่งออกไฟล์ Excel (.xlsx) และพิมพ์ทะเบียนประจำปี
- ใช้ได้ทั้งคอมพิวเตอร์และมือถือ ไม่ต้องติดตั้งแพ็กเกจเพิ่ม มีแค่ Node.js ก็พอ

## เริ่มใช้งาน

1. ติดตั้ง [Node.js](https://nodejs.org) รุ่น 18 ขึ้นไป
2. เปิดเซิร์ฟเวอร์
   - Windows: ดับเบิลคลิก `start.bat`
   - หรือพิมพ์คำสั่งในโฟลเดอร์นี้: `npm start`
3. เปิดเบราว์เซอร์ไปที่ <http://localhost:3000>
   (เครื่องอื่นในวง LAN เดียวกันเข้าได้ตามที่อยู่ที่แสดงตอนเปิดเซิร์ฟเวอร์ เช่น `http://192.168.1.10:3000`)
4. ครั้งแรก กด **นำเข้าไฟล์ Excel** แล้วเลือกไฟล์ทะเบียนหนังสือเดิม
   ระบบจะแสดงจำนวนรายการของแต่ละปีให้ตรวจก่อน เมื่อนำเข้าแล้วจะบอก **เลขถัดไป** ของแต่ละปี

ต้องการเปลี่ยนพอร์ต: `PORT=8080 npm start` (Windows: `set PORT=8080` แล้วจึง `npm start`)

## การออกเลข

- กด **+ ออกเลขหนังสือใหม่** กรอกเรื่องและผู้ปฏิบัติ แล้วกด **ออกเลข**
  ช่อง ที่ / จาก / ถึง ระบบเติมให้จากหนังสือฉบับล่าสุด
- เมื่อออกเลขแล้วจะแสดงเลขที่ได้ เช่น `ที่ สธ 0315.3(2.7.1)/26` พร้อมปุ่มคัดลอก
- เลขถัดไปคือเลขที่ต่อจากเลขที่ออกล่าสุด ถ้าเลขนั้นมีอยู่แล้วในทะเบียน ระบบจะข้ามไปเลขว่างถัดไปให้
- ลบรายการที่เพิ่งออกล่าสุด → ได้เลขนั้นคืน ส่วนการลบรายการเก่าที่อยู่กลางทะเบียนจะไม่ทำให้เลขถอยกลับ
- ต้องการเริ่ม/ข้ามเลขเอง กด **ตั้งเลขถัดไปเอง** ใต้เลขถัดไป

## การนำเข้า Excel

- แต่ละชีตต้องตั้งชื่อเป็นปี พ.ศ. เช่น `2569` และมีแถวหัวตารางตามรูปแบบข้างต้น
- แถวที่มีแต่เลขลำดับ (เตรียมเลขไว้ล่วงหน้า) จะไม่ถูกนำเข้า
- แถวที่ไม่มีเลขและมีแต่ข้อความในช่องเรื่อง จะต่อท้ายเรื่องของรายการก่อนหน้า
- วันที่อ่านได้ทั้งเซลล์วันที่ของ Excel และข้อความ เช่น `19/3/2025`, `13/8-69`, `5/25/2569`
  ปีที่พิมพ์เป็น พ.ศ. หรือ ค.ศ. ระบบแปลงให้เอง วันที่ที่อ่านไม่ได้จะเก็บเป็นข้อความไว้ให้แก้ภายหลัง
- เลขถัดไปหลังนำเข้า = เลขว่างตัวแรกนับจากเลขแรกของปีนั้น
- การนำเข้าซ้ำจะ **แทนที่** ข้อมูลของปีที่อยู่ในไฟล์ (ปีอื่นไม่เปลี่ยน) และสำรองข้อมูลเดิมไว้ใน `data/backups/`
- นำเข้าทางบรรทัดคำสั่งก็ได้ (ปิดเซิร์ฟเวอร์ก่อน): `npm run import -- ทะเบียนหนังสือ.xlsx`

**ส่งออก Excel** ได้ไฟล์รูปแบบเดียวกับไฟล์เดิม (ชีตละปี) ใช้สำรองข้อมูลหรือนำกลับมานำเข้าใหม่ได้

## ข้อมูลเก็บที่ไหน

ข้อมูลทั้งหมดอยู่ในไฟล์ `data/registry.json` บนเครื่องที่เปิดเซิร์ฟเวอร์
(มี `registry.json.bak` เป็นสำเนาก่อนการบันทึกครั้งล่าสุด)
ควรสำรองไฟล์นี้หรือกด **ส่งออก Excel** เป็นระยะ

โฟลเดอร์ `data/` และไฟล์ `.xlsx` ไม่ถูกเก็บใน git เพื่อไม่ให้ข้อมูลทะเบียนจริงหลุดขึ้น repository

> ระบบนี้ไม่มีการเข้าสู่ระบบ ใครเปิดหน้าเว็บได้ก็ออกเลข/แก้ไขได้ ควรใช้ภายในเครือข่ายของหน่วยงานเท่านั้น

## สำหรับผู้พัฒนา

```
npm test        # ทดสอบการอ่านไฟล์ Excel การออกเลข และ API
```

| ไฟล์ | หน้าที่ |
| --- | --- |
| `server.js` | เว็บเซิร์ฟเวอร์และ API (`/api/state`, `/api/records`, `/api/counters/:ปี`, `/api/import`, `/api/export.xlsx`) |
| `lib/store.js` | เก็บข้อมูลและออกเลข |
| `lib/importer.js` | แปลงชีต Excel เป็นรายการทะเบียน (วันที่ อักขระไทย แถวว่าง) |
| `lib/xlsx.js` | อ่าน/เขียนไฟล์ .xlsx โดยไม่ใช้แพ็กเกจภายนอก |
| `public/` | หน้าเว็บ (HTML/CSS/JS ล้วน) |
