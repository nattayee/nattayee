# 🤖 AI Crypto Trader

เว็บเทรดคริปโตที่ให้ AI (Claude) วิเคราะห์กราฟและตัดสินใจ **ซื้อ / ขาย / ถือ** ให้อัตโนมัติ
พร้อมระบบคุมความเสี่ยงที่ AI ข้ามไม่ได้

> ⚠️ **เวอร์ชันนี้เป็นโหมดเงินจำลอง (Paper trading)** ใช้ราคาตลาดจริงจาก Binance แต่ไม่ส่งคำสั่งซื้อขายจริง
> ควรรันทดสอบอย่างน้อย 2–4 สัปดาห์ แล้วดูว่าชนะการถือเฉยๆ (buy & hold) ได้จริงหรือไม่ ก่อนคิดจะใช้เงินจริง
> AI ไม่สามารถรับประกันกำไรได้ และนี่ไม่ใช่คำแนะนำการลงทุน

## ทำงานอย่างไร

```
ทุก N นาที (ค่าเริ่มต้น 60) สำหรับแต่ละเหรียญ:
  ดึงแท่งเทียน 200 แท่งจาก Binance
    → คำนวณ indicator (EMA 20/50/200, RSI, MACD, ATR, Bollinger)
    → ส่งให้ Claude พร้อมสถานะพอร์ต → ได้คำตอบ JSON: BUY/SELL/HOLD + ความมั่นใจ + ขนาด + SL/TP + เหตุผล (ภาษาไทย)
    → ตัวคุมความเสี่ยง (risk.js) ตรวจ/ปรับลด/ปฏิเสธ
    → ส่งคำสั่งในบัญชีจำลอง

ทุก 15 วินาที (ทำงานตลอดแม้บอทหยุด):
  อัปเดตราคา → ตัดขาดทุน (Stop-loss) / ทำกำไร (Take-profit) อัตโนมัติ → ตรวจ kill switch รายวัน
```

**กฎความเสี่ยงที่ AI ข้ามไม่ได้** (ปรับได้ในหน้าตั้งค่า ⚙️)

| กฎ | ค่าเริ่มต้น |
|---|---|
| ขนาดสูงสุดต่อเหรียญ | 25% ของพอร์ต |
| ถือเหรียญรวมไม่เกิน | 80% ของพอร์ต |
| ความมั่นใจขั้นต่ำก่อนส่งคำสั่ง | 60% |
| Stop-loss สูงสุด | 10% (ทุกการซื้อต้องมี SL) |
| Kill switch: ขาดทุนวันนี้เกิน | 5% → หยุดบอททันที |
| Spot เท่านั้น | ไม่มี leverage, ไม่ขายชอร์ต, ไม่ซื้อเพิ่มในเหรียญที่ถืออยู่ |

## เริ่มใช้งาน

ต้องมี [Node.js](https://nodejs.org) เวอร์ชัน 20 ขึ้นไป

```bash
cd ai-trader
npm install
cp .env.example .env      # แล้วใส่ ANTHROPIC_API_KEY ในไฟล์ .env
npm start
```

เปิด **http://localhost:3000** แล้วกด **⚡ วิเคราะห์ตอนนี้** เพื่อดู AI ตัดสินใจครั้งแรก หรือ **▶ เริ่มบอท** ให้ทำงานต่อเนื่อง

- **API key**: สมัครที่ [console.anthropic.com](https://console.anthropic.com) → API Keys
- **ไม่มี key ก็ลองได้**: บอทจะใช้กลยุทธ์ indicator ในตัว (EMA trend + MACD + RSI) แทน AI
- **ข้อมูลเก็บที่** `data/state.json` (ปิดแล้วเปิดใหม่ พอร์ตยังอยู่) — รีเซ็ตได้ในหน้าตั้งค่า

## ค่าใช้จ่าย AI

ทุกการตัดสินใจคือการเรียก Claude 1 ครั้ง (ส่งข้อมูลราว 3,000 tokens) หน้าเว็บจะแสดงค่าใช้จ่ายจริงที่ใช้ไป
ค่าที่ส่งผลมากที่สุด:

- **จำนวนเหรียญ × ความถี่** — 3 เหรียญ ทุก 60 นาที = 72 ครั้ง/วัน; ทุก 15 นาที = 288 ครั้ง/วัน (แพงขึ้น 4 เท่า)
  ถ้าใช้แท่งเทียน 1 ชม. การถามทุก 15 นาทีส่วนใหญ่ก็เห็นข้อมูลเดิม
- **โมเดล** (`CLAUDE_MODEL`) — `claude-opus-5-5` ($4/$20 ต่อล้าน tokens) แม่นสุด,
  `claude-sonnet-5-5` ($2/$10) ถูกลงครึ่งหนึ่ง, `claude-haiku-5-5` ถูกที่สุด
- **ความลึกในการคิด** (`CLAUDE_EFFORT`) — `low` / `medium` / `high`

ลองรันสัก 1 วันแล้วดูตัวเลข "ค่าใช้ AI" บนหน้าเว็บก่อนปรับ

## ตั้งค่า (.env)

| ตัวแปร | ค่าเริ่มต้น | ความหมาย |
|---|---|---|
| `ANTHROPIC_API_KEY` | – | key สำหรับ Claude |
| `AI_PROVIDER` | อัตโนมัติ | `claude` หรือ `rules` |
| `CLAUDE_MODEL` | `claude-opus-5-5` | โมเดลที่ใช้ตัดสินใจ |
| `CLAUDE_EFFORT` | `medium` | ความลึกในการคิด |
| `MARKET_DATA` | `auto` | `binance` / `simulated` / `auto` (ลอง Binance ก่อน ไม่ได้ใช้ราคาจำลอง) |
| `PORT` / `HOST` | `3000` / `127.0.0.1` | ค่าเริ่มต้นเปิดได้เฉพาะเครื่องตัวเอง |
| `DASHBOARD_PASSWORD` | – | ตั้งรหัสผ่านหน้าเว็บ (**ต้องตั้ง** ถ้าเปิด `HOST=0.0.0.0` หรือขึ้น server) |

## โครงสร้างโค้ด

```
server/
  index.js       เว็บเซิร์ฟเวอร์ + REST API
  bot.js         loop ของบอท: ดึงข้อมูล → AI → ตรวจความเสี่ยง → ส่งคำสั่ง
  ai.js          Claude (structured output) + กลยุทธ์สำรองแบบ rule-based
  risk.js        กฎความเสี่ยง
  portfolio.js   บัญชีเงินจำลอง (ค่าธรรมเนียม, กำไร/ขาดทุน, SL/TP)
  market.js      ราคาจาก Binance / ราคาจำลอง
  indicators.js  EMA, RSI, MACD, ATR, Bollinger
public/          หน้าเว็บ (กราฟใช้ TradingView Lightweight Charts)
test/            npm test
```

## ก้าวต่อไป: เทรดเงินจริง

ยังไม่ได้ทำในเวอร์ชันนี้ โดยตั้งใจ เพราะควรพิสูจน์ผลในโหมดจำลองก่อน แนวทางที่แนะนำ:

1. รันโหมดจำลองให้นานพอ เทียบกับ buy & hold
2. ต่อ **Binance Spot Testnet** (เงินทดสอบ แต่ส่งคำสั่งผ่าน API จริง)
3. ใช้เงินจริงจำนวนน้อย ผ่าน exchange ที่ได้รับอนุญาตจาก ก.ล.ต. (เช่น Bitkub สำหรับคู่เงินบาท)
   - สร้าง API key แบบ **เทรดได้อย่างเดียว ห้ามถอน** และล็อก IP
   - เก็บ key ในเซิร์ฟเวอร์เท่านั้น ห้ามใส่ในหน้าเว็บ
