# TRS-398 Output Calibration — ใช้บัญชีร่วมกับ LPCH RO Workspace

ไฟล์ในโฟลเดอร์นี้คือแอป TRS-398 (จาก branch `claude/brave-volta-pjvcd3`) ที่เพิ่มการเข้าสู่ระบบด้วยบัญชี LPCH RO Workspace

| ไฟล์ | คืออะไร |
| --- | --- |
| `WebApp.gs` | โค้ดเซิร์ฟเวอร์ — วางแทน `Code.gs` ทั้งไฟล์ในโปรเจกต์ Apps Script ของ TRS-398 |
| `index.html` | หน้าแอป (โหลดจาก GitHub อัตโนมัติตาม `PAGE_URL` ไม่ต้องวาง) |
| `gas-bridge.js` | ต้นฉบับของส่วนเข้าสู่ระบบในหน้าแอป (อยู่ใน `index.html` แล้ว) |

## ทำงานอย่างไร

- **กดจาก LPCH:** หน้า MP › Dosimetry → **เปิดแอป ↗** ลิงก์แนบ "บัตรผ่าน" (`?sso=…`) ที่ใช้ได้ครั้งเดียว อายุ 2 นาที
  แอปนำบัตรไปแลกกับ LPCH (`ssoRedeem`) แล้วเข้าสู่ระบบให้ทันที ไม่ต้องกรอกรหัส
- **เปิดแอปตรง ๆ:** หน้าแรกมีช่อง **ชื่อผู้ใช้ หรืออีเมล + รหัสผ่าน** ของ LPCH (ตรวจที่ LPCH ผ่านคำสั่ง `login` — แอปนี้ไม่เก็บรหัสผ่าน)
  ปุ่ม **เข้าสู่ระบบด้วย Google** ยังใช้ได้เหมือนเดิม
- **สิทธิ์:** ใช้ได้เฉพาะวิชาชีพใน `LPCH_ROLES` (ค่าเริ่มต้น `['MP']`) และผู้ดูแลระบบ LPCH — ใส่ `['*']` ถ้าให้สมาชิกทุกคนใช้ได้
- **ตรวจซ้ำทุกครั้งที่ใช้** (เก็บผลไว้ 5 นาที): ถ้า admin ระงับบัญชีใน LPCH ก็จะเข้าแอปนี้ไม่ได้ด้วย
- เข้าสู่ระบบแล้วจำไว้ 7 วัน มุมขวาบนแสดงชื่อ · อีเมล และปุ่ม **ออกจากระบบ**
- ทุกรายงานบันทึกอีเมลของบัญชี LPCH ในคอลัมน์ **ผู้บันทึก (Gmail)** และชื่อ (username, วิชาชีพ) ในคอลัมน์ **บัญชี LPCH**
- บัญชี LPCH ต้องมีอีเมล (ใช้เป็นชื่อผู้บันทึก) — บัญชีเก่าที่ไม่มีอีเมลให้เพิ่มที่ "บัญชีของฉัน"
- แก้ไขแล้ว: ปุ่ม Google เดิมส่ง token กลับมาแล้วหน้าเว็บไม่ได้รับ (หาแท็ก `<head>` ไม่เจอ) ตอนนี้ใส่ไว้หลัง `<meta charset>`

## ติดตั้ง (บัญชี nattayee@gmail.com)

1. **LPCH RO Workspace** ต้องใช้ `Code.gs` เวอร์ชันที่มี `ssoTicket` / `ssoRedeem` แล้ว Deploy **New version**
   (Deploy แบบ Who has access: **Anyone** — แอป TRS-398 เรียก API ของ LPCH จากเซิร์ฟเวอร์)
2. **TRS-398:** เปิดโปรเจกต์ Apps Script ของ TRS-398 → วาง `WebApp.gs` ทับ `Code.gs` ทั้งไฟล์ → บันทึก
   (บรรทัดสุดท้ายต้องเป็น `// ----- สิ้นสุดไฟล์ WebApp.gs …`)
3. ⚙ Project Settings → Script properties → เพิ่ม `LPCH_URL` = URL `/exec` ของ LPCH RO Workspace → Save
4. รันฟังก์ชัน `setupLogin` หนึ่งครั้ง (อนุญาตสิทธิ์ "เชื่อมต่อบริการภายนอก" ถ้าถาม) — Log จะแสดงค่า LPCH_URL ที่ตั้งไว้
5. Deploy → Manage deployments → Edit → **New version** ทั้ง deployment ① แอป และ ② เข้าสู่ระบบ

## เมื่อแก้หน้าแอป

แก้ `gas-bridge.js` แล้วนำไปแทนส่วน `/* ---- gas-bridge.js ---- */` ใน `index.html`
(หรือแก้ใน branch ต้นฉบับแล้ว build ด้วย `trs398-calculator/apps-script/build_webapp.py`) → commit + push
หน้าแอปจะอัปเดตภายใน 10 นาที
