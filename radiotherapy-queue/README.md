# ระบบนัดคิวผู้ป่วยฉายรังสี

กลุ่มงานรังสีรักษา โรงพยาบาลมะเร็งลำปาง

เว็บแอปสำหรับนัดคิวผู้ป่วยฉายรังสีในห้องฉาย 3 ห้อง ได้แก่ **Infinity (L1)**, **Precise (L2)** และ **VersaHD (L3)**

## ความสามารถ

| เมนู | รายละเอียด |
|---|---|
| **นัดผู้ป่วย** | บันทึกข้อมูลผู้ป่วย (HN, ชื่อ, การวินิจฉัย, แพทย์) เลือกห้องฉาย L1/L2/L3 เลือกชนิดเทคนิคการฉาย (2D, 3D-CRT, IMRT, VMAT, SRS, SRT, SBRT, Electron, TBI) กำหนดจำนวนครั้ง วันทำ CT Sim **วันเริ่มฉาย** และเวลานัด |
| **วันทำ CBCT** | กำหนด *วันนัดทำ CBCT ก่อนเริ่มฉาย* (Verification) และ *รูปแบบ CBCT ระหว่างฉาย*: เฉพาะ Fx 1, 3 ครั้งแรกแล้วสัปดาห์ละครั้ง, สัปดาห์ละครั้ง, ทุกครั้ง หรือติ๊กเลือกวันเองในตาราง |
| **คำนวณวันฉายอัตโนมัติ** | ข้ามเสาร์-อาทิตย์และวันหยุดราชการ กด “งด” เพื่อเลื่อนวันฉายเฉพาะรายออกไปต่อท้ายคอร์ส |
| **ตรวจคิวชน** | เตือนเมื่อเวลานัดซ้อนกับผู้ป่วยรายอื่นในห้องเดียวกัน (รวมวันนัด CBCT ก่อนฉาย) และปุ่ม **หาเวลาว่างอัตโนมัติ** ที่หาเวลาที่ว่างตลอดทั้งคอร์ส |
| **แดชบอร์ด** | สรุปจำนวนนัดฉาย/CBCT/ผู้ป่วยเริ่มฉายใหม่วันนี้ ผู้ป่วยกำลังฉาย/รอเริ่มฉาย การใช้เครื่องแต่ละห้อง กราฟจำนวนผู้ป่วยต่อวันแยกห้อง กราฟเทคนิคการฉาย รายการเริ่มฉายใหม่ นัด CBCT และผู้ป่วยใกล้ฉายครบ (เลือกวันที่ดูย้อนหลัง/ล่วงหน้าได้) |
| **ปฏิทินการนัด** | ปฏิทินรายเดือนแสดงจำนวนผู้ป่วยแต่ละห้อง วันเริ่มฉาย วัน CBCT และวันหยุด กรองตามห้อง/ประเภทนัด คลิกวันที่เพื่อดูคิวรายห้องเรียงตามเวลา และพิมพ์ตารางประจำวัน |
| **รายชื่อผู้ป่วย** | ค้นหา/กรองตามห้อง เทคนิค สถานะ แสดงความคืบหน้าการฉาย พิมพ์ **ใบนัด** ให้ผู้ป่วย และส่งออก CSV (เปิดด้วย Excel ได้) |
| **ตั้งค่า** | เวลาเปิด-ปิดของแต่ละห้อง ช่วงเวลานัด วันทำการ วันหยุด (มีวันหยุดราชการที่ตรงกับวันที่เดิมทุกปีให้แล้ว) สำรอง/นำเข้าข้อมูล และข้อมูลตัวอย่างสำหรับทดลองใช้ |

## การติดตั้งและใช้งาน

ต้องมี [Node.js](https://nodejs.org) เวอร์ชัน 18 ขึ้นไป (ไม่ต้องติดตั้งแพ็กเกจเพิ่ม)

```bash
cd radiotherapy-queue
npm start
```

แล้วเปิดเบราว์เซอร์ที่ `http://localhost:3000` เครื่องอื่นในเครือข่ายโรงพยาบาลเข้าใช้ได้ที่ `http://<IP เครื่องเซิร์ฟเวอร์>:3000`

ตัวแปรที่ปรับได้:

| ตัวแปร | ค่าเริ่มต้น | ความหมาย |
|---|---|---|
| `PORT` | `3000` | พอร์ตของเว็บ |
| `HOST` | `0.0.0.0` | ที่อยู่ที่รับการเชื่อมต่อ (ใช้ `127.0.0.1` ถ้าต้องการให้ใช้ได้เฉพาะเครื่องนี้) |
| `DB_FILE` | `data/db.json` | ไฟล์เก็บข้อมูล |

ข้อมูลทั้งหมดเก็บในไฟล์ `data/db.json` ควรสำรองไฟล์นี้เป็นประจำ (หรือใช้ปุ่ม “ดาวน์โหลดไฟล์สำรอง” ในหน้าตั้งค่า)

> หากวางไฟล์ในโฟลเดอร์ `public/` บนเว็บเซิร์ฟเวอร์ทั่วไปโดยไม่รัน `server.mjs` ระบบจะทำงานใน **โหมดออฟไลน์** และเก็บข้อมูลไว้ในเบราว์เซอร์ของเครื่องนั้นเท่านั้น (มุมขวาบนจะแสดงสถานะการเชื่อมต่อ)

## ความปลอดภัยของข้อมูลผู้ป่วย

ระบบนี้ **ยังไม่มีการล็อกอิน** และควรใช้งานภายในเครือข่ายของโรงพยาบาลเท่านั้น หากจะเปิดให้เข้าถึงจากภายนอก ควรติดตั้งหลัง reverse proxy ที่มี HTTPS และการยืนยันตัวตน เพื่อให้สอดคล้องกับ พ.ร.บ.คุ้มครองข้อมูลส่วนบุคคล (PDPA)

## โครงสร้างโปรเจกต์

```
radiotherapy-queue/
├── server.mjs              เซิร์ฟเวอร์ + REST API (/api/state, /api/appointments, /api/settings)
├── public/
│   ├── index.html          หน้าเว็บ
│   ├── css/style.css       รูปแบบหน้าเว็บ (รองรับมือถือและโหมดมืด)
│   └── js/
│       ├── schedule.js     ตรรกะคำนวณวันฉาย, CBCT, ตรวจคิวชน (ใช้ร่วมกันทั้งเว็บและเซิร์ฟเวอร์)
│       ├── store.js        เชื่อมต่อ API / โหมดออฟไลน์
│       └── app.js          หน้าจอแดชบอร์ด ปฏิทิน รายชื่อ ฟอร์มนัด ตั้งค่า
└── test/                   ชุดทดสอบ (npm test)
```

## การทดสอบ

```bash
npm test
```
