# ติดตั้งบน Google Apps Script

ระบบนัดคิวผู้ป่วยฉายรังสีเวอร์ชันนี้ทำงานบน Google Apps Script และเก็บข้อมูลใน **Google Sheet** ไม่ต้องมีเครื่องเซิร์ฟเวอร์

## ไฟล์ที่ต้องคัดลอก

| ไฟล์ในโฟลเดอร์นี้ | สร้างใน Apps Script เป็น | ชื่อที่ต้องตั้ง |
|---|---|---|
| `Code.gs` | สคริปต์ (Script) | `Code` |
| `Schedule.gs` | สคริปต์ (Script) | `Schedule` |
| `Index.html` | HTML | `Index` |
| `appsscript.json` | (ไม่บังคับ) ไฟล์ manifest | — |

> ชื่อไฟล์ต้องตรงตามตาราง (ตัวพิมพ์เล็ก-ใหญ่มีผล) ตอนสร้างไฟล์ให้พิมพ์แค่ชื่อ เช่น `Index` ไม่ต้องพิมพ์ `.html` เอง
> หรือคัดลอกโค้ดทีละไฟล์จากหน้า [โค้ด Apps Script](https://claude.ai/artifact/7ZjAGMnKgETfqioSGtBtjf) ได้โดยไม่ต้องดาวน์โหลด

## ขั้นตอน

1. สร้างโปรเจกต์ Apps Script ได้ 2 แบบ เลือกแบบใดก็ได้
   - **แบบ ก:** เปิด [script.google.com](https://script.google.com) › โปรเจกต์ใหม่ (ระบบจะสร้าง Google Sheet ให้เองตอนรัน `setup`)
   - **แบบ ข:** สร้าง Google Sheet ก่อน แล้วไปที่เมนู **ส่วนขยาย › Apps Script** (ระบบจะใช้ Sheet นั้นเก็บข้อมูล)
2. ในไฟล์ `Code.gs` ที่มีอยู่แล้ว ลบโค้ดเดิมออก แล้ววางเนื้อหาจาก `Code.gs`
3. กด **＋ › สคริปต์** พิมพ์ชื่อ `Schedule` แล้ววางเนื้อหาจาก `Schedule.gs`
4. กด **＋ › HTML** พิมพ์ชื่อ `Index` ลบโค้ดตัวอย่างในไฟล์ออก แล้ววางเนื้อหาจาก `Index.html` (ไฟล์นี้มีทั้งหน้าเว็บ รูปแบบ และสคริปต์)
5. กดบันทึก (💾) เลือกฟังก์ชัน **`setup`** ในแถบด้านบน แล้วกด **เรียกใช้** → อนุญาตสิทธิ์ตามที่ Google ขอ
   - ระบบจะสร้างแผ่นงาน `Appointments`, `Holidays`, `Settings` และแสดง **ลิงก์ของ Google Sheet** ในบันทึกการดำเนินการ
   - ถ้าต้องการใช้ Sheet ที่มีอยู่แล้ว ให้วางลิงก์ของ Sheet ใน `var SPREADSHEET_URL = '';` บรรทัดบน ๆ ของ `Code.gs` ก่อนรัน
6. กด **การทำให้ใช้งานได้ › การทำให้ใช้งานได้รายการใหม่** → เลือกประเภท **เว็บแอป**
   - **ดำเนินการในฐานะ:** `ผู้ใช้ที่เข้าถึงเว็บแอป`
   - **ผู้ที่มีสิทธิ์เข้าถึง:** `ทุกคนที่มีบัญชี Google` หรือ `ทุกคนใน <โดเมนโรงพยาบาล>` ถ้าใช้ Google Workspace ของโรงพยาบาล
7. คัดลอก **URL ของเว็บแอป** ส่งให้เจ้าหน้าที่
8. เปิดลิงก์ Google Sheet จากขั้นที่ 5 แล้ว **แชร์** (สิทธิ์ผู้แก้ไข) ให้เฉพาะเจ้าหน้าที่ที่ต้องใช้ระบบ

### ทำไมตั้งค่าแบบนี้

เมื่อเลือก *ดำเนินการในฐานะผู้ใช้ที่เข้าถึง* ระบบจะอ่าน/เขียน Sheet ด้วยบัญชีของผู้ใช้แต่ละคน
**คนที่ไม่ได้รับแชร์ Sheet จะเปิดเว็บได้แต่โหลดข้อมูลไม่ได้** สิทธิ์การเข้าถึงข้อมูลผู้ป่วยจึงควบคุมได้จากการแชร์ Sheet ที่เดียว และมีประวัติการแก้ไขใน Sheet ว่าใครแก้อะไร

> ⚠️ **ห้าม** เลือก “ดำเนินการในฐานะ: ฉัน” คู่กับ “ทุกคน” เพราะจะทำให้ใครก็ตามที่มีลิงก์เห็นข้อมูลผู้ป่วยได้

ผู้ใช้แต่ละคนจะถูกขอให้อนุญาตสิทธิ์หนึ่งครั้งเมื่อเปิดเว็บแอปครั้งแรก

## แก้ปัญหา

| ข้อความผิดพลาด | สาเหตุและวิธีแก้ |
|---|---|
| `No HTML file named Index was found` | ยังไม่ได้สร้างไฟล์ HTML ชื่อ `Index` หรือชื่อไม่ตรง (เช่น `index`, `Index.html.html`) ให้เปลี่ยนชื่อไฟล์เป็น `Index` |
| `No HTML file named Styles was found` | มาจากโค้ดเวอร์ชันก่อน ให้คัดลอก `Code.gs` และ `Index.html` ชุดใหม่มาวางทับ แล้วลบไฟล์ `Styles` และ `JavaScript` ทิ้งได้ |
| `ยังไม่ได้ตั้งค่าระบบ` | เปิดหน้าแก้ไขสคริปต์ เลือกฟังก์ชัน `setup` แล้วกดเรียกใช้หนึ่งครั้ง |
| `กรุณาเปิด Apps Script จากเมนู ส่วนขยาย > Apps Script …` | มาจากโค้ดเวอร์ชันก่อน ให้คัดลอก `Code.gs` ชุดใหม่มาวางทับ แล้วรัน `setup` อีกครั้ง ระบบจะสร้าง Google Sheet ให้เอง |
| หน้าเว็บขึ้น “โหลดข้อมูลไม่สำเร็จ” | บัญชีที่เปิดยังไม่ได้รับแชร์ Google Sheet ให้เจ้าของแชร์ Sheet ให้บัญชีนั้น |
| แก้โค้ดแล้วหน้าเว็บยังเหมือนเดิม | ต้องทำให้ใช้งานได้เป็น **เวอร์ชันใหม่** ตามหัวข้อด้านล่าง (หรือทดสอบผ่านลิงก์ “ทดสอบการทำให้ใช้งานได้”) |

## การอัปเดตโค้ดภายหลัง

วางโค้ดใหม่ทับไฟล์เดิม แล้วไปที่ **ทำให้ใช้งานได้ › จัดการการทำให้ใช้งานได้ (Manage deployments)** › ✏️ › เวอร์ชัน **เวอร์ชันใหม่** › ทำให้ใช้งานได้ — URL เดิมจะใช้ได้ต่อ

## ข้อมูลใน Google Sheet

| แผ่นงาน | เนื้อหา |
|---|---|
| `Appointments` | นัดผู้ป่วย 1 แถวต่อ 1 ราย (วันที่เก็บเป็นข้อความรูปแบบ `ปปปป-ดด-วว` ปี ค.ศ., เวลา `ชช:นน`) |
| `Holidays` | วันหยุด (`date`, `name`) — เพิ่ม/ลบในหน้า “ตั้งค่า” ของระบบ หรือพิมพ์ใน Sheet โดยตรงก็ได้ |
| `Settings` | เวลาเปิด-ปิดห้อง วันทำการ ช่วงเวลานัด |

ควรแก้ไขข้อมูลนัดผ่านหน้าเว็บเป็นหลัก ถ้าแก้ใน Sheet โดยตรงให้คงรูปแบบวันที่/เวลาไว้ตามเดิม และ **อย่าแก้หรือลบคอลัมน์ `id`**

## สำหรับผู้พัฒนา

ไฟล์ `Index.html` และ `Schedule.gs` สร้างจากโค้ดใน `public/` ด้วยคำสั่ง

```bash
npm run build:gas
```

ให้แก้ที่ต้นฉบับใน `public/` แล้วสร้างใหม่ ส่วน `Code.gs` และ `appsscript.json` แก้ในโฟลเดอร์นี้โดยตรง
ชุดทดสอบ (`npm test`) จำลอง Google Sheet เพื่อทดสอบ `Code.gs` และตรวจว่าไฟล์ที่สร้างตรงกับต้นฉบับ
