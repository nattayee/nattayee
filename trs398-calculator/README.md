# TRS-398 Output Calibration

เว็บแอปคำนวณ output calibration ของเครื่องเร่งอนุภาค (photon และ electron) ตามโปรโตคอล **IAEA TRS-398**
เป็นไฟล์ static ไม่ต้องติดตั้ง: เปิด `index.html` ในเบราว์เซอร์ได้ทันที

## สูตรที่ใช้

```
D_w,Q(z_ref) = M_Q · N_D,w,Q0 · k_Q,Q0
M_Q          = M̄ · k_TP · k_elec · k_pol · k_s · k_vol
Output       = 100 · D_w(z_ref) / (PDD(z_ref)/100 หรือ TMR(z_ref)) / MU   [cGy/MU ที่ z_max]
```

| ปัจจัย | วิธีคำนวณ |
|---|---|
| k_TP | (273.2 + T)/(273.2 + 20) · 101.325/P |
| k_pol | (\|M+\| + \|M−\|) / 2M |
| k_s | two-voltage, ตาราง 4.VII (pulsed / pulsed-scanned) หรือสูตร continuous (Co-60) |
| TPR20,10 | 1.2661 · PDD20,10 − 0.0595 |
| R50 | 1.029 · I50 − 0.06 (I50 ≤ 10 g/cm²), 1.059 · I50 − 0.37 (I50 > 10 g/cm²) |
| z_ref | photon 10 g/cm²; electron 0.6 · R50 − 0.1 g/cm² |

k_Q,Q0 ใส่ค่าโดยตรง หรือวางแถวตารางของหัววัด (จาก TRS-398 ตาราง 6.III / 7.III) แล้วให้แอปประมาณค่าเชิงเส้น
แอปไม่ได้ฝังตาราง k_Q ไว้ ผู้ใช้ต้องนำค่ามาจากเอกสาร TRS-398 หรือใบรับรองการสอบเทียบ

## ไฟล์

- `index.html` — หน้าเว็บ (UI ภาษาไทย)
- `trs398.js` — ฟังก์ชันคำนวณ (pure functions) ใช้ได้ทั้งในเบราว์เซอร์และ Node (`require('./trs398.js')`)

> เครื่องมือช่วยคำนวณเท่านั้น ผลการวัดทางคลินิกควรได้รับการทวนสอบอิสระโดยนักฟิสิกส์การแพทย์
