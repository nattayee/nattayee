# TRS-398 Output Calibration

เว็บแอปคำนวณ output calibration ของเครื่องเร่งอนุภาค (photon และ electron) ตามโปรโตคอล **IAEA TRS-398**
เป็นไฟล์ static ไม่ต้องติดตั้ง: เปิด `index.html` ในเบราว์เซอร์ได้ทันที

## สูตรที่ใช้

```
D_w,Q(z_ref) = M_Q · N_D,w,Q0 · k_Q,Q0
M_Q          = M̄ · k_TP · k_elec · k_pol · k_s · k_vol
Output       = 100 · D_w(z_ref) / (PDD(z_ref)/100 หรือ TMR(z_ref)) / MU   [cGy/MU ที่ z_max]
```

| ปัจจัย | วิธีคำนวณ |
|---|---|
| k_TP | (273.2 + T)/(273.2 + 20) · 101.325/P |
| k_pol | (\|M+\| + \|M−\|) / 2M |
| k_s | two-voltage, ตาราง 4.VII (pulsed / pulsed-scanned) หรือสูตร continuous (Co-60) |
| TPR20,10 | 1.2661 · PDD20,10 − 0.0595 |
| R50 | 1.029 · I50 − 0.06 (I50 ≤ 10 g/cm²), 1.059 · I50 − 0.37 (I50 > 10 g/cm²) |
| z_ref | photon 10 g/cm²; electron 0.6 · R50 − 0.1 g/cm² |

## ข้อมูลหน่วยงาน (`lpch-data.js`)

นำเข้าจาก Google Sheet **TG398 LPCH Ver 20260924** (sheet `0. List` และ `1. kQ,Q0 table`):

- เครื่องเร่งอนุภาค Infinity-6023, Precise2-3461, VersaHD-4406 พร้อม z_max, TMR(z_ref) ของ photon และ R50, N_D,w, PDD(z_ref), Kcross ของ electron แต่ละพลังงาน
- หัววัด Farmer TW30013 (s/n 0458, 9849) และ PP TW34001 (s/n 1208), เครื่องวัดประจุ PTW Webline s/n 2103
- ตาราง k_Q: photon (TW10003) ตาม TPR20,10 และ electron (Roos) ตาม R50

k_Q,Q0 ของ photon คำนวณจาก TPR20,10 (= M20/M10 ที่ SAD 100) ด้วยการประมาณค่าเชิงเส้นระหว่างสองจุดของตาราง
เหมือนสูตร FORECAST ใน Sheet ส่วน electron ใช้ N_D,w ที่สอบเทียบในลำรังสีแต่ละพลังงาน (k_Q,Q0 = 1)
ยังเลือกใส่ k_Q เอง หรือวางตารางของหัววัดอื่นได้

### การเชื่อมกับ Sheet

แอปอ่านข้อมูลหลักจาก Sheet ตามลำดับนี้ (`sheet-sync.js` อ่านไฟล์ด้วย SheetJS):

1. **Google Drive connector** — เมื่อเปิดหน้าใน claude.ai แอปจะดึง Sheet เป็น .xlsx ผ่าน connector ของผู้ใช้ทุกครั้งที่เปิด และกด "ดึงข้อมูลจาก Sheet" เพื่อดึงใหม่ได้
2. **ไฟล์ .xlsx** — เมื่อเปิด `index.html` เองนอก claude.ai ให้ดาวน์โหลด Sheet (File → Download → .xlsx) แล้วกด "เลือกไฟล์ .xlsx"
3. **สำเนาในแอป** — `lpch-data.js` ใช้เมื่อสองทางแรกไม่ได้

ข้อมูลที่ดึงสำเร็จครั้งล่าสุดจะถูกจำไว้ในเบราว์เซอร์ เมื่อดึงข้อมูลใหม่ ค่าที่มาจาก Sheet (TMR, z_max, R50, N_D,w, k_Q) ของพลังงานที่เลือกจะถูกเขียนทับ ส่วนค่าที่อ่านได้จะคงไว้

## ก่อนปรับและหลังปรับ (Before / After adjust)

ติ๊ก "ปรับ output แล้ววัดซ้ำ" แล้วใส่ T, P และ M1 หลังปรับ ค่า k_pol, k_s, k_Q, k_Q,Qcross, N_D,w และ TMR/PDD
ใช้จากผลก่อนปรับ เหมือนใน Sheet (T31/R33)

## บันทึกรายงานลง Sheet

ใน Google Drive มีโฟลเดอร์ **TRS-398 Output Reports** ซึ่งมี:

- **TRS-398 Output Log (LPCH)**: แท็บ `Log` เก็บรายงานหนึ่งแถวต่อการวัดหนึ่งครั้ง และแท็บ `วิธีใช้`
- **Inbox**: ปุ่ม "ส่งรายงานไปที่ Sheet" ในแอปสร้างไฟล์รายงาน (หัวคอลัมน์ + ค่า) ไว้ที่นี่ผ่าน Google Drive connector
- **Imported**: ไฟล์ที่นำเข้าแล้ว
- **ReportImporter.gs**: Apps Script (ต้นฉบับอยู่ที่ `apps-script/ReportImporter.gs`)

ปลายทางของรายงานย้ายไปเป็นของ **nattayee@gmail.com**: โฟลเดอร์แชร์ให้เป็น Editor แล้ว จากนั้นโอนความเป็นเจ้าของ
(Drive → แชร์ → nattayee → โอนการเป็นเจ้าของ แล้ว nattayee กดยอมรับ) ให้ครบทุกไฟล์: โฟลเดอร์หลัก, Inbox, Imported,
Log Sheet และ ReportImporter.gs ID และลิงก์ไม่เปลี่ยน แอปและสคริปต์จึงไม่ต้องแก้ ผู้ที่ส่งรายงานต้องมีสิทธิ์ Editor ในโฟลเดอร์ Inbox

ติดตั้ง Apps Script ครั้งเดียว (ทำด้วยบัญชี nattayee หลังรับโอนแล้ว เพื่อให้ trigger ทำงานในชื่อเจ้าของ): เปิด Log Sheet → Extensions → Apps Script → วางโค้ด → บันทึก → Run `setup`
แล้วอนุญาตสิทธิ์ สคริปต์จะนำเข้าไฟล์ใน Inbox ลงแท็บ `Log` ทุก 5 นาที (หรือเมนู TRS-398 → นำเข้ารายงานตอนนี้)
จับคู่คอลัมน์ตามชื่อหัวคอลัมน์ ข้าม Report ID ที่มีแล้ว และระบายสีช่องผล PASS/FAIL

หัวคอลัมน์กำหนดไว้ที่ `report-log.js` (COLUMNS) ต้องตรงกับแถวที่ 1 ของแท็บ Log
ถ้ารายงานมีคอลัมน์ใหม่ สคริปต์จะเพิ่มคอลัมน์ต่อท้ายให้เอง
(คอลัมน์ "ชนิด QA" และ "หมายเหตุผู้วัด" เพิ่มภายหลัง จะถูกต่อท้ายแท็บ Log ในการนำเข้าครั้งแรก ย้ายตำแหน่งคอลัมน์ได้เพราะจับคู่ตามชื่อ)

## Dashboard ย้อนหลัง

แท็บ "Dashboard ย้อนหลัง" (หรือเปิดลิงก์ต่อท้าย `#dashboard`) อ่านแท็บ Log ของ Log Sheet ผ่าน Google Drive connector
(หรือเลือกไฟล์ .xlsx ของ Log) รวมกับรายงานที่ส่งจากเบราว์เซอร์นี้แต่ยังไม่ถูกนำเข้า (ติดป้าย "รอนำเข้า")

- ตัวกรอง: เครื่อง, พลังงาน, ชนิด QA, ช่วงเวลา (3/6/12 เดือน/ทั้งหมด)
- การ์ดสรุป: จำนวนการวัด, ค่าล่าสุด, %Diff เฉลี่ย ± SD, จำนวน ผ่าน/เฝ้าระวัง/เกินเกณฑ์ และจำนวนครั้งที่ปรับเครื่อง
- กราฟแนวโน้ม %Diff (ก่อนปรับ) ตามวันที่ แยกเส้นตามพลังงาน แถบเฝ้าระวังและเกณฑ์ยอมรับจากค่าในหน้าคำนวณ
  จุดกลวงคือค่าหลังปรับ เลื่อนเมาส์หรือกดลูกศรซ้าย/ขวาเพื่อดูค่าแต่ละวัน
- ตารางรายการการวัดทั้งหมดตามตัวกรอง
- ปุ่ม "ดูข้อมูลตัวอย่าง" เมื่อ Log ยังว่าง (ติดป้ายว่าเป็นตัวอย่าง)

## ภาษา (ไทย / EN)

ปุ่ม ไทย | EN มุมขวาบนสลับภาษาทั้งหน้า (จำไว้ในเบราว์เซอร์) `i18n.js` แปลข้อความไทยทุกส่วนเป็นอังกฤษจากพจนานุกรม DICT
รวมถึงข้อความที่แอปสร้างภายหลัง (ข้อความเตือน สถานะ Dashboard) วันที่แสดงตามภาษา
ชื่อนักฟิสิกส์ ชื่อไฟล์ และข้อมูลที่ส่งเข้า Log ไม่ถูกแปล (ค่าใน Log ยังเป็นภาษาไทยเหมือนเดิม)
เพิ่มข้อความไทยใหม่ในแอปเมื่อไร ให้เพิ่มคำแปลใน DICT ด้วย

## ไฟล์

- `index.html` — หน้าเว็บ (UI ภาษาไทย)
- `lpch-data.js` — สำเนาข้อมูลเครื่อง หัววัด และตาราง k_Q จาก Sheet
- `i18n.js` — สลับภาษาไทย/อังกฤษ
- `dashboard.js` — Dashboard ย้อนหลัง (อ่าน Log, การ์ดสรุป, กราฟแนวโน้ม, ตาราง)
- `report-log.js` — แปลงผลคำนวณเป็นแถวรายงานและส่งเข้า Inbox
- `apps-script/ReportImporter.gs` — สคริปต์นำเข้ารายงานใน Log Sheet
- `sheet-sync.js` — อ่าน workbook (Drive connector หรือไฟล์ .xlsx) เป็นข้อมูลชุดเดียวกับ `lpch-data.js`
- `trs398.js` — ฟังก์ชันคำนวณ (pure functions) ใช้ได้ทั้งในเบราว์เซอร์และ Node (`require('./trs398.js')`)
