# ติดตั้งเป็น Google Apps Script Web App

ใช้ 2 ไฟล์ในโฟลเดอร์นี้:

| ไฟล์ใน Apps Script | คัดลอกจาก |
|---|---|
| `WebApp.gs` (ไฟล์สคริปต์) | `WebApp.gs` |
| `index` (ไฟล์ HTML) | `index.html` |

## ขั้นตอน

1. เปิด **TRS-398 Output Log (LPCH)** → ส่วนขยาย (Extensions) → Apps Script
   (โปรเจกต์เดียวกับ ReportImporter.gs ได้ ชื่อฟังก์ชันไม่ชนกัน)
2. กด **+ → สคริปต์** ตั้งชื่อ `WebApp` แล้ววางเนื้อหา `WebApp.gs`
3. กด **+ → HTML** ตั้งชื่อ `index` (ไม่ต้องมี .html) ลบของเดิมแล้ววางเนื้อหา `index.html` ทั้งไฟล์
4. บันทึก แล้ว **ทำให้ใช้งานได้ (Deploy) → การทำให้ใช้งานได้รายการใหม่ → เว็บแอป**
   - ดำเนินการในฐานะ (Execute as): **ฉัน (Me)** — แอปอ่าน/เขียน Sheet ด้วยสิทธิ์ของเจ้าของ
   - ผู้มีสิทธิ์เข้าถึง (Who has access): **เฉพาะตัวฉัน** หรือ **ทุกคนที่มีบัญชี Google** ตามที่ต้องการ
     (ทุกคนที่เปิดลิงก์ได้จะบันทึกรายงานลง Log ได้)
5. อนุญาตสิทธิ์ (Drive, Sheets, เชื่อมต่อบริการภายนอก) แล้วเปิด URL ของเว็บแอป

## ต่างจากเวอร์ชัน claude.ai อย่างไร

- อ่าน Sheet ข้อมูลหลักและ Log ผ่าน `WebApp.gs` (ไม่ต้องใช้ Google Drive connector)
- ปุ่ม "ส่งรายงานไปที่ Sheet" เขียนลงแท็บ **Log ทันที** (ไม่ผ่าน Inbox / ไม่ต้องรอ 5 นาที) และไม่บันทึก Report ID ซ้ำ
- web app อ่านได้เฉพาะ 2 ไฟล์ที่กำหนดใน `WEBAPP` ใน `WebApp.gs` ถ้าเปลี่ยน Sheet ให้แก้ ID ตรงนั้น

## เมื่อแก้โค้ดของแอป

`index.html` ที่นี่สร้างจากไฟล์ต้นฉบับ (`index.html` และ `*.js` ในโฟลเดอร์ `trs398-calculator`) ด้วย

```
python3 trs398-calculator/apps-script/build_webapp.py
```

แล้ววางไฟล์ใหม่ทับใน Apps Script และ Deploy → จัดการการทำให้ใช้งานได้ → แก้ไข → เวอร์ชันใหม่
