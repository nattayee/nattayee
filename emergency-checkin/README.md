# 🚨 ระบบเช็คอินกรณีเกิดภัยพิบัติ (Google Sheets)

ระบบนับยอดพนักงานตอนอพยพ (ไฟไหม้ แผ่นดินไหว ซ้อมหนีไฟ) ใช้ **Google Sheets เป็นฐานข้อมูล** และ **Google Apps Script** ทำหน้าเว็บ
ไม่ต้องมีเซิร์ฟเวอร์ และไม่มีค่าใช้จ่าย

| หน้า | ใครใช้ | ทำอะไร |
|---|---|---|
| **หน้าเช็คอิน** (สแกน QR ที่จุดรวมพล) | พนักงาน | ค้นหาชื่อ แล้วกด "ปลอดภัย" หรือ "ต้องการความช่วยเหลือ" ครั้งต่อไปเครื่องจะจำชื่อไว้ให้ กดปุ่มเดียวจบ |
| **Dashboard** (ใช้ PIN) | ผู้ควบคุมเหตุ / จป. | ดูยอดแบบเรียลไทม์ **คนที่ยังไม่เช็คอินขึ้นก่อน** กรองตามแผนก/ชั้นได้ โทรออกได้ทันที และบันทึกสถานะแทนได้ |

## ใช้กับไฟล์ "รายชื่อเจ้าหน้าที่แต่ละโซน"

ระบบอ่านรายชื่อจาก**ทุกชีตที่ชื่อขึ้นต้นด้วย "โซน"** โดยตรง ไม่ต้องย้ายข้อมูลไปที่อื่น

- **หน่วยงาน** มาจากแถวหัวที่ merge ไว้ (เช่น "งานรังสีรักษา") ส่วน **ตำแหน่ง** มาจากคอลัมน์ "ตำแหน่ง"
- **ตอนนี้ใช้ "ชื่อ-สกุล" เป็นตัวระบุตัวคน** ค้นหาได้โดยไม่ต้องพิมพ์คำนำหน้า และไม่ต้องสนใจช่องว่าง
- ชื่อที่อยู่หลายโซน (เช่น โซน 1 และโซน 5) จะรวมเป็นคนเดียว และเขียนสถานะลงทุกโซนที่มีชื่อนั้น
- ข้ามแถวหมายเหตุที่ขึ้นต้นด้วย "-" เช่น "- เช็ครายชื่อที่โซน 2 -"

### เชื่อมกับคอลัมน์ "สถานะ" เดิม (อยู่ / ลา / ไม่ทราบ)
| เหตุการณ์ | คอลัมน์สถานะในชีตโซน |
|---|---|
| ประกาศเหตุ / เริ่มเหตุการณ์ใหม่ | "อยู่" ทั้งหมดเปลี่ยนเป็น "ไม่ทราบ" (**"ลา" คงไว้**) |
| เช็คอินปลอดภัย หรือขอความช่วยเหลือ | เปลี่ยนเป็น "อยู่" |
| ผู้ควบคุมกด "ลา · ไม่อยู่ในพื้นที่" | เปลี่ยนเป็น "ลา" |

ใช้ได้ทั้งสองทาง หัวหน้าโซนยังเลือกสถานะเองในชีตได้เหมือนเดิม Dashboard จะเห็นทันที:
- เลือก **"ลา"** ระบบไม่นับคนนั้นในยอดที่ต้องตามหา (ควรเลือกให้คนที่ลาตั้งแต่เช้า)
- เลือก **"อยู่"** ระบบนับว่าปลอดภัย

ถ้าไม่ต้องการให้ระบบเขียนลงชีตโซน ตั้ง `SYNC_ZONE_STATUS` = `FALSE` ในชีต Config

### เมื่อพร้อมใส่รหัสพนักงาน
เพิ่มคอลัมน์ในแต่ละชีตโซน (เช่น คอลัมน์ I) ให้หัวตารางแถวที่ 2 มีคำว่า **"รหัสพนักงาน"** แล้วกรอกรหัส
ระบบจะใช้รหัสแทนชื่อเองโดยไม่ต้องแก้โค้ด และเปิดใช้ข้อมูลสแกนนิ้ว/ใบหน้าได้ (ตั้ง `USE_SCAN_LOG` = `TRUE` แล้ววางข้อมูลในชีต `ScanLog`)
คนที่ยังไม่มีรหัส ระบบจะถือว่าอยู่ในอาคารไว้ก่อน เพื่อไม่ให้ตกหล่น

## ผู้มีสิทธิ์ใช้ Dashboard (ชีต Roles)

ชีต `Roles` มีคอลัมน์ **ชื่อ-สกุล | บทบาท | วันเดือนปีเกิด (ใช้เป็น PIN) | หมายเหตุ**
แต่ละคนเข้า Dashboard ด้วย**วันเกิดของตัวเอง** ระบบจึงรู้ว่าใครประกาศเหตุ ใครปิดเหตุ และใครบันทึกสถานะแทน

| บทบาท | ดู Dashboard / บันทึกสถานะแทน | ประกาศ / ยืนยัน / ปิดเหตุ |
|---|:---:|:---:|
| ผู้บัญชาการ | ✓ | ✓ |
| รองผู้บัญชาการ (ผู้ทำหน้าที่แทน) | ✓ | ✓ |
| เจ้าหน้าที่ศูนย์ | ✓ | – |

**กรอกวันเกิด:** แบบ `วว/ดด/ปปปป` ปี พ.ศ. เช่น `15/03/2530` (คอลัมน์นี้ตั้งเป็นข้อความไว้ และกรอกผิดรูปแบบไม่ได้)
**เข้าระบบ:** พิมพ์ตัวเลข 8 หลัก `15032530` ระบบรับปี ค.ศ. `15031987` ด้วย กันคนสับสนตอนรีบ

- แก้ชื่อในวงเล็บเป็นชื่อจริง แถวที่ชื่อยังขึ้นต้นด้วย "(" ใช้เข้าระบบไม่ได้
- **ควรมีผู้ทำหน้าที่แทนอย่างน้อย 2 คน** เช่น รองผู้อำนวยการ และหัวหน้าเวร/ผู้ตรวจการนอกเวลา เพราะเหตุอาจเกิดตอนกลางคืนหรือวันหยุด
- **ถ้าวันเกิดของสองคนตรงกัน** ทั้งคู่จะเข้าระบบไม่ได้ ใช้เมนู 🚨 → *ตรวจวันเกิดซ้ำในชีต Roles* เพื่อเช็ก ถ้าซ้ำให้คนหนึ่งใส่ตัวเลข 8 หลักอื่นแทนวันเกิด
- เปลี่ยนผู้บัญชาการได้ทันทีด้วยการแก้ชีต Roles ไม่ต้อง Deploy ใหม่ ลบแถวออกแล้วคนนั้นเข้าไม่ได้ทันที
- `ADMIN_PIN` ในชีต Config ใช้ได้เฉพาะตอนที่ชีต Roles ยังไม่มีรายชื่อจริง
- ใส่วันเกิดผิด ระบบจะหน่วงเวลา 1.5 วินาที เพื่อกันการสุ่มเดา

> ⚠ **วันเกิดเดาได้ง่ายกว่ารหัสสุ่ม** เพื่อนร่วมงานมักรู้วันเกิดกัน ถ้ามีคนเดาถูก จะเข้า Dashboard แทนผู้บัญชาการได้
> จำกัดคนที่เปิดชีต Roles ได้ และ**อย่ากรอกวันเกิดของผู้บัญชาการและผู้ทำหน้าที่แทนในคอลัมน์ "วันเกิด" ของชีตโซน**

**ถ้ามีคนเช็คอินก่อนผู้บัญชาการประกาศเหตุ** ระบบจะเริ่มนับยอดให้อัตโนมัติ ข้อมูลไม่หาย Dashboard จะแสดงแถบแจ้งเตือน
และปุ่ม **"ยืนยันเหตุการณ์"** ให้ผู้บัญชาการระบุประเภทเหตุ ยอดที่นับไว้แล้วจะนับต่อ
ชีต `Events` บันทึกชื่อ**ผู้ประกาศเหตุ**และ**ผู้ปิดเหตุ**ไว้ทุกครั้ง

## ติดตั้ง (ประมาณ 15 นาที)

1. เปิดไฟล์ **รายชื่อเจ้าหน้าที่แต่ละโซน** → เมนู **ส่วนขยาย → Apps Script**
2. ในไฟล์ `Code.gs` ลบโค้ดเดิม แล้ววางโค้ดจาก [`Code.gs`](Code.gs)
3. กด **+ → HTML** สร้างไฟล์ `CheckIn` และ `Dashboard` แล้ววางโค้ดจาก [`CheckIn.html`](CheckIn.html) และ [`Dashboard.html`](Dashboard.html)
4. (ไม่บังคับ) ⚙ Project Settings → ติ๊ก *Show "appsscript.json"* แล้ววาง [`appsscript.json`](appsscript.json) เพื่อตั้งเขตเวลาไทย
5. เลือกฟังก์ชัน `setup` → **▶ Run** → อนุญาตสิทธิ์
   ระบบจะแจ้งจำนวนเจ้าหน้าที่ที่อ่านได้แยกรายโซน และสร้างชีต `Config`, `Events`, `CheckIns`, `ScanLog` ไว้ท้ายไฟล์ ชีตโซนเดิมไม่ถูกแก้
6. ในชีต **Roles** ใส่ชื่อผู้บัญชาการ ผู้ทำหน้าที่แทน และเจ้าหน้าที่ศูนย์ พร้อมวันเกิด (`วว/ดด/ปปปป` พ.ศ.)
   ในชีต **Config** ตั้งจุดรวมพลใน `POINTS` (รูปแบบ `A:ลานหน้าอาคาร,B:สนามหลัง`)
7. **Deploy → New deployment → Web app** · *Execute as*: **Me** · *Who has access*: **Anyone**
8. คัดลอก **Web app URL** ที่ลงท้ายด้วย `/exec` ไปวางในชีต **Config** แถว `WEB_APP_URL`
9. กลับไปที่ชีต รีเฟรช แล้วใช้เมนู **🚨 เช็คอินฉุกเฉิน → สร้าง QR Code จุดรวมพล** ระบบจะสร้างชีต `QR` ให้ พิมพ์ไปติดที่จุดรวมพล
   (ห้ามใช้ลิงก์ที่ลงท้ายด้วย `/dev` เพราะเจ้าหน้าที่จะเปิดไม่ได้)

> ถ้าแก้โค้ดภายหลัง: Deploy → Manage deployments → ✏ → Version: *New version* เพื่อให้ URL เดิมใช้โค้ดใหม่
> ถ้าแก้รายชื่อในชีตโซน ระบบจะล้างแคชให้เอง หรือกดเมนู **ล้างแคชรายชื่อ**

### ตั้งค่าในชีต Config
| ตั้งค่า | ค่าเริ่มต้น | ความหมาย |
|---|---|---|
| `ADMIN_PIN` | `1234` | PIN สำรอง ใช้ได้เฉพาะตอนชีต Roles ยังว่าง |
| `POINTS` | `A:จุดรวมพล 1,B:จุดรวมพล 2` | จุดรวมพล (รหัส:ชื่อ) |
| `ZONE_SHEET_PREFIX` | `โซน` | ชีตที่ชื่อขึ้นต้นด้วยคำนี้คือรายชื่อ |
| `SYNC_ZONE_STATUS` | `TRUE` | เขียนผลลงคอลัมน์ "สถานะ" ในชีตโซน |
| `USE_SCAN_LOG` | `FALSE` | ใช้ข้อมูลสแกนนิ้ว/ใบหน้า (ต้องมีรหัสพนักงานก่อน) |
| `SCAN_LOOKBACK_HOURS` | `16` | ดูข้อมูลสแกนย้อนหลังกี่ชั่วโมง |
| `WEB_APP_URL` | (ว่าง) | ลิงก์ Web app ที่ลงท้ายด้วย `/exec` ใช้สร้าง QR |

## ขั้นตอนตอนเกิดเหตุ

1. **ผู้บัญชาการหรือผู้ทำหน้าที่แทน** เปิด Dashboard ด้วยวันเกิด 8 หลัก → กด **ประกาศเหตุฉุกเฉิน** → เลือกประเภทเหตุ
   (ถ้าพนักงานเช็คอินก่อนที่ผู้ควบคุมจะกดประกาศ ระบบจะเริ่มเหตุการณ์ให้อัตโนมัติ)
2. **พนักงาน** ไปถึงจุดรวมพลแล้วสแกน QR → ค้นหาชื่อ → กด ✅ ปลอดภัย
   - ถ้ามีเพื่อนที่ไม่มีมือถือ ให้กด **เช็คอินแทนเพื่อน**
   - ถ้าเน็ตไม่ดี ข้อมูลจะเก็บรอไว้ในเครื่องและส่งให้อัตโนมัติ (ห้ามปิดหน้าเว็บ)
3. **ผู้ควบคุม** ดูกล่องสีส้ม **ยังไม่เช็คอิน** และการ์ดรายโซนที่บอกว่าแต่ละโซนค้างกี่คน → แตะชื่อเพื่อบันทึกสถานะแทน
   หัวหน้าโซนเลือก "อยู่" / "ลา" ในชีตโซนได้เหมือนเดิม ยอดใน Dashboard จะอัปเดตตาม
4. เมื่อนับยอดครบ กด **ปิดเหตุการณ์** ข้อมูลทั้งหมดจะเก็บอยู่ในชีต `Events` และ `CheckIns` ใช้ทำรายงานต่อได้
   กดปุ่ม **พิมพ์** ได้ถ้าต้องการรายชื่อเป็นกระดาษ

## ข้อควรรู้ / ข้อจำกัด

- **รองรับเจ้าหน้าที่ประมาณ 400 คน** Google Apps Script รับคำขอพร้อมกันได้ราว 30 รายการ ถ้ามีคนกดพร้อมกันเยอะ บางเครื่องจะขึ้นว่า "กำลังลองส่งใหม่" แล้วส่งสำเร็จเองภายในไม่กี่วินาที
- **ต้องมีแผนสำรองเป็นกระดาษเสมอ** สั่งพิมพ์รายชื่อพนักงานแยกตามแผนกเก็บไว้ที่จุดรวมพล เผื่อกรณีเน็ตหรือไฟดับทั้งพื้นที่
- **ควรซ้อมใช้จริง** ตอนซ้อมหนีไฟประจำปี ให้เลือกประเภท "ซ้อมอพยพหนีไฟ" แล้วดูว่าใช้เวลานับยอดกี่นาที
- การเข้าระบบด้วยวันเกิดเป็นการป้องกันระดับพื้นฐาน จำกัดคนที่แก้ไขไฟล์ได้ เพราะคนที่เปิดชีต Roles ได้จะเห็นวันเกิดทุกคน

## โครงสร้างชีต

| ชีต | เนื้อหา |
|---|---|
| `โซน...` (เดิม) | รายชื่อเจ้าหน้าที่ ระบบอ่านชื่อ/หน่วยงาน/ตำแหน่ง และเขียนคอลัมน์ "สถานะ" |
| `Roles` | ผู้มีสิทธิ์ใช้ Dashboard: ชื่อ, บทบาท, วันเดือนปีเกิด (ใช้เป็น PIN) |
| `Config` | การตั้งค่า |
| `Events` | ประวัติเหตุการณ์ (เริ่ม/สิ้นสุด) |
| `CheckIns` | ทุกการเช็คอิน (ใคร สถานะ จุดไหน เวลา ใครบันทึก) ใช้ทำรายงาน |
| `ScanLog` | ข้อมูลสแกนนิ้ว/ใบหน้า (ใช้เมื่อมีรหัสพนักงานแล้ว) |
| `QR` | QR Code ของแต่ละจุดรวมพล (สร้างจากเมนู) |
