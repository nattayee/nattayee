# 🚨 ระบบเช็คอินกรณีเกิดภัยพิบัติ (Google Sheets)

ระบบนับยอดพนักงานตอนอพยพ (ไฟไหม้ แผ่นดินไหว ซ้อมหนีไฟ) ใช้ **Google Sheets เป็นฐานข้อมูล** และ **Google Apps Script** ทำหน้าเว็บ
ไม่ต้องมีเซิร์ฟเวอร์ และไม่มีค่าใช้จ่าย

| หน้า | ใครใช้ | ทำอะไร |
|---|---|---|
| **หน้าเช็คอิน** (สแกน QR ที่จุดรวมพล) | พนักงาน | ค้นหาชื่อ แล้วกด "ปลอดภัย" หรือ "ต้องการความช่วยเหลือ" ครั้งต่อไปเครื่องจะจำชื่อไว้ให้ กดปุ่มเดียวจบ |
| **Dashboard** (ใช้ PIN) | ผู้ควบคุมเหตุ / จป. | ดูยอดแบบเรียลไทม์ **คนที่ยังไม่เช็คอินขึ้นก่อน** กรองตามแผนก/ชั้นได้ โทรออกได้ทันที และบันทึกสถานะแทนได้ |

## จุดเด่น: ใช้ข้อมูลสแกนนิ้ว/ใบหน้าที่มีอยู่แล้ว

ระบบจะนำข้อมูลจากเครื่องสแกนเข้างาน (ชีต `ScanLog`) มาดูว่า **วันนี้ใครอยู่ในอาคารจริง**

- **ยังไม่เช็คอิน** = สแกนเข้างานแล้ว แต่ยังไม่มาเช็คอินที่จุดรวมพล → **ต้องตามหา**
- **ไม่ได้สแกนเข้างาน** = วันนี้ไม่ได้มาทำงาน (ลา/หยุด) → ไม่ต้องตามหา
- ถ้าคนไหนสแกน "ออก" เป็นรายการล่าสุด ระบบจะถือว่าออกจากอาคารแล้ว
- ถ้ายังไม่มีข้อมูลสแกน ระบบจะ**นับพนักงานทุกคน**แทน เพื่อไม่ให้ตกหล่น

## ติดตั้ง (ประมาณ 15 นาที)

### 1. สร้าง Google Sheet และใส่โค้ด
1. สร้าง Google Sheet ใหม่ เช่น ตั้งชื่อว่า `ระบบเช็คอินฉุกเฉิน`
2. เปิดเมนู **ส่วนขยาย → Apps Script**
3. ในไฟล์ `Code.gs` ลบโค้ดเดิมออก แล้ววางโค้ดจาก [`Code.gs`](Code.gs)
4. กด **+ → HTML** สร้างไฟล์ชื่อ `CheckIn` แล้ววางโค้ดจาก [`CheckIn.html`](CheckIn.html)
5. กด **+ → HTML** สร้างไฟล์ชื่อ `Dashboard` แล้ววางโค้ดจาก [`Dashboard.html`](Dashboard.html)
6. (ไม่บังคับ) ไปที่ ⚙ Project Settings → ติ๊ก *Show "appsscript.json"* แล้ววางโค้ดจาก [`appsscript.json`](appsscript.json) เพื่อตั้งเขตเวลาเป็น `Asia/Bangkok`
7. เลือกฟังก์ชัน `setup` แล้วกด **▶ Run** และกดอนุญาตสิทธิ์ ระบบจะสร้างชีตให้ครบ

### 2. ใส่รายชื่อพนักงานจาก Excel
เปิดชีต **Employees** แล้ว copy คอลัมน์จาก Excel มาวางตามลำดับนี้ เริ่มที่แถว 2:

| A: รหัสพนักงาน | B: ชื่อ-นามสกุล | C: แผนก | D: ชั้น/อาคาร | E: เบอร์โทร |
|---|---|---|---|---|

> ⚠ **รหัสพนักงานต้องตรงกับรหัสในเครื่องสแกนนิ้ว/ใบหน้า** ระบบใช้รหัสนี้จับคู่ข้อมูล
> ถ้ารหัสขึ้นต้นด้วย 0 (เช่น 00123) ระบบตั้งคอลัมน์ A เป็นข้อความไว้แล้ว เลข 0 จะไม่หาย

### 3. ตั้งค่าในชีต Config
| ตั้งค่า | ตัวอย่าง | ความหมาย |
|---|---|---|
| `ADMIN_PIN` | `5821` | **ต้องเปลี่ยน** PIN สำหรับเข้า Dashboard |
| `POINTS` | `A:ลานจอดรถหน้า,B:สนามหลัง` | จุดรวมพล (รหัส:ชื่อ) |
| `USE_SCAN_LOG` | `TRUE` | ใช้ข้อมูลสแกนนิ้ว/ใบหน้าหรือไม่ |
| `SCAN_LOOKBACK_HOURS` | `16` | ดูข้อมูลสแกนย้อนหลังกี่ชั่วโมง (เผื่อกะดึก) |

### 4. Deploy เป็นเว็บ
1. ใน Apps Script กด **Deploy → New deployment → Web app**
2. *Execute as*: **Me** / *Who has access*: **Anyone**
   (ถ้าทุกคนใช้ Google Workspace ของบริษัท เลือก *Anyone within องค์กร* ได้ แต่พนักงานต้องล็อกอินก่อน ซึ่งจะช้ากว่าตอนเกิดเหตุ)
3. คัดลอก URL ที่ได้มาเก็บไว้
4. กลับไปที่ Google Sheet แล้วรีเฟรช จะมีเมนู **🚨 เช็คอินฉุกเฉิน → สร้าง QR Code จุดรวมพล**
   ระบบจะสร้างชีต `QR` ที่มี QR ของแต่ละจุดรวมพล → **พิมพ์ไปติดที่จุดรวมพล** และติดที่บันไดหนีไฟด้วยก็ได้

> ถ้าแก้โค้ดภายหลัง ให้ไปที่ Deploy → Manage deployments → ✏ → Version: *New version* เพื่อให้ URL เดิมใช้โค้ดใหม่

## นำข้อมูลสแกนนิ้ว/ใบหน้าเข้าชีต `ScanLog`

ชีต `ScanLog` ใช้ 3 คอลัมน์: `รหัสพนักงาน | วันเวลาที่สแกน | ประเภท (เข้า/ออก - ไม่บังคับ)`
รองรับรูปแบบเวลา `2026-11-21 08:01`, `21/11/2026 08:01` และ `21/11/2569 08:01` (ปี พ.ศ.)

เลือกวิธีตามระบบที่บริษัทใช้:

| วิธี | ความเร็วข้อมูล | วิธีทำ |
|---|---|---|
| **A. วางข้อมูลเองทุกเช้า** | ช้าที่สุด | Export ไฟล์ Excel/CSV จากโปรแกรมเครื่องสแกน (เช่น ZKTeco, HIP) แล้ว copy มาวางหลังเวลาเข้างาน |
| **B. ซิงก์อัตโนมัติ** | ทุก 5–15 นาที | ถ้าโปรแกรมสแกนเก็บข้อมูลในฐานข้อมูล (SQL/Access) หรือมี API ให้ IT เขียนสคริปต์ส่งข้อมูลมาที่ชีตตามรอบเวลา |
| **C. ไม่ใช้** | - | ตั้ง `USE_SCAN_LOG` = `FALSE` ระบบจะนับพนักงานทุกคน แล้วผู้ควบคุมกด "ไม่อยู่ในพื้นที่" ให้คนที่ลาแทน |

ข้อมูลเก่าใน ScanLog ลบได้เป็นระยะ ระบบดูเฉพาะช่วง `SCAN_LOOKBACK_HOURS` ล่าสุด

## ขั้นตอนตอนเกิดเหตุ

1. **ผู้ควบคุม** เปิด Dashboard → กด **ประกาศเหตุฉุกเฉิน** → เลือกประเภทเหตุ
   (ถ้าพนักงานเช็คอินก่อนที่ผู้ควบคุมจะกดประกาศ ระบบจะเริ่มเหตุการณ์ให้อัตโนมัติ)
2. **พนักงาน** ไปถึงจุดรวมพลแล้วสแกน QR → ค้นหาชื่อ → กด ✅ ปลอดภัย
   - ถ้ามีเพื่อนที่ไม่มีมือถือ ให้กด **เช็คอินแทนเพื่อน**
   - ถ้าเน็ตไม่ดี ข้อมูลจะเก็บรอไว้ในเครื่องและส่งให้อัตโนมัติ (ห้ามปิดหน้าเว็บ)
3. **ผู้ควบคุม** ดูกล่องสีส้ม **ยังไม่เช็คอิน** → กดเบอร์เพื่อโทรตาม → แตะชื่อเพื่อบันทึกสถานะแทน
4. เมื่อนับยอดครบ กด **ปิดเหตุการณ์** ข้อมูลทั้งหมดจะเก็บอยู่ในชีต `Events` และ `CheckIns` ใช้ทำรายงานต่อได้
   กดปุ่ม **พิมพ์** ได้ถ้าต้องการรายชื่อเป็นกระดาษ

## ข้อควรรู้ / ข้อจำกัด

- **รองรับพนักงานประมาณ 300 คน** Google Apps Script รับคำขอพร้อมกันได้ราว 30 รายการ ถ้ามีคนกดพร้อมกันเยอะ บางเครื่องจะขึ้นว่า "กำลังลองส่งใหม่" แล้วส่งสำเร็จเองภายในไม่กี่วินาที
- **ต้องมีแผนสำรองเป็นกระดาษเสมอ** สั่งพิมพ์รายชื่อพนักงานแยกตามแผนกเก็บไว้ที่จุดรวมพล เผื่อกรณีเน็ตหรือไฟดับทั้งพื้นที่
- **ควรซ้อมใช้จริง** ตอนซ้อมหนีไฟประจำปี ให้เลือกประเภท "ซ้อมอพยพหนีไฟ" แล้วดูว่าใช้เวลานับยอดกี่นาที
- PIN ของ Dashboard เป็นการป้องกันระดับพื้นฐาน อย่าแชร์ลิงก์พร้อม PIN ในกลุ่มที่เปิดกว้าง เพราะในหน้า Dashboard มีเบอร์โทรพนักงาน
- ถ้าแก้รายชื่อในชีต Employees แล้วหน้าเว็บยังไม่อัปเดต ให้กดเมนู **ล้างแคชรายชื่อพนักงาน** (ปกติระบบจะอัปเดตเองภายใน 10 นาที)

## โครงสร้างชีต

| ชีต | เนื้อหา |
|---|---|
| `Employees` | รายชื่อพนักงาน (วางจาก Excel) |
| `ScanLog` | ข้อมูลสแกนนิ้ว/ใบหน้า |
| `Events` | ประวัติเหตุการณ์ (เริ่ม/สิ้นสุด) |
| `CheckIns` | ทุกการเช็คอิน (ใคร สถานะ จุดไหน เวลา ใครบันทึก) ระบบใช้รายการล่าสุดของแต่ละคน |
| `Config` | การตั้งค่า |
| `QR` | QR Code ของแต่ละจุดรวมพล (สร้างจากเมนู) |
