# 🗓️ ระบบจัดการวันลา (Leave Management)

เว็บแอปสำหรับจัดการวันลาของพนักงานในองค์กร ไม่ต้องติดตั้งแพ็กเกจเพิ่ม ใช้แค่ Node.js (เวอร์ชัน 22.5 ขึ้นไป) ฐานข้อมูลเป็น SQLite ไฟล์เดียว

## ความสามารถ

**พนักงาน**
- ดูวันลาคงเหลือแยกตามประเภท (ใช้ไป / รออนุมัติ / คงเหลือ) เลือกดูย้อนหลังรายปีได้
- ยื่นใบลาแบบเต็มวัน หรือครึ่งวันเช้า/บ่าย ระบบคำนวณจำนวนวันให้อัตโนมัติ (ไม่นับเสาร์-อาทิตย์และวันหยุด)
- ป้องกันการลาซ้อนวัน และการลาเกินสิทธิ์
- ดูประวัติการลา และยกเลิกใบลาที่ยังไม่เริ่ม
- ปฏิทินรวม ดูว่าใครลาวันไหน
- เปลี่ยนรหัสผ่าน

**หัวหน้างาน**
- อนุมัติ / ไม่อนุมัติ (พร้อมหมายเหตุ) ใบลาของลูกทีมโดยตรง
- รายงานสรุปการใช้วันลาของทีม ดาวน์โหลดเป็น CSV (เปิดใน Excel ได้ภาษาไทยไม่เพี้ยน)

**ผู้ดูแลระบบ (HR)**
- เพิ่ม/แก้ไข/ปิดใช้งานพนักงาน กำหนดแผนก บทบาท และหัวหน้าผู้อนุมัติ
- ตั้งค่าประเภทการลาและสิทธิ์วันลาต่อปี (ค่าเริ่มต้น: ลาป่วย 30, ลากิจ 6, ลาพักร้อน 10, ลาคลอด 98, ลาบวช 15)
- จัดการวันหยุดประจำปี (ระบบใส่วันหยุดราชการที่วันที่ตายตัวให้แล้ว ส่วนวันหยุดทางจันทรคติและวันหยุดชดเชยให้เพิ่มเองตามประกาศแต่ละปี)
- อนุมัติใบลาได้ทุกใบ (ใบลาของพนักงานที่ไม่มีหัวหน้าจะมาที่ผู้ดูแลระบบ)

## เริ่มใช้งาน

```bash
cd leave-app
npm start
```

เปิด http://localhost:3000

บัญชีทดลอง:

| บทบาท | อีเมล | รหัสผ่าน |
|---|---|---|
| ผู้ดูแลระบบ | admin@example.com | admin1234 |
| หัวหน้างาน | manager@example.com | password |
| พนักงาน | somsri@example.com | password |

> ⚠️ ก่อนใช้งานจริง: ตั้ง `SEED_DEMO=0` และ `ADMIN_PASSWORD=...` ตอนรันครั้งแรก (หรือลบไฟล์ `data.db` แล้วรันใหม่) จากนั้นเข้าสู่ระบบด้วย admin เพื่อเพิ่มพนักงานจริง และเปลี่ยนอีเมล admin ในหน้าตั้งค่า

## ตัวแปรสภาพแวดล้อม

| ตัวแปร | ค่าเริ่มต้น | ความหมาย |
|---|---|---|
| `PORT` | `3000` | พอร์ตของเว็บ |
| `DB_FILE` | `data.db` | ตำแหน่งไฟล์ฐานข้อมูล (สำรองข้อมูลด้วยการคัดลอกไฟล์นี้) |
| `SEED_DEMO` | `1` | `0` = ไม่สร้างผู้ใช้ทดลอง (มีผลเฉพาะตอนสร้างฐานข้อมูลครั้งแรก) |
| `ADMIN_PASSWORD` | `admin1234` | รหัสผ่าน admin ตอนสร้างฐานข้อมูลครั้งแรก |
| `COOKIE_SECURE` | – | ตั้งเป็น `1` เมื่อให้บริการผ่าน HTTPS |

## โครงสร้าง

```
server.js         จุดเริ่มต้น เปิด HTTP server
src/db.js         โครงสร้างฐานข้อมูล ข้อมูลเริ่มต้น และการเข้ารหัสรหัสผ่าน (scrypt)
src/days.js       คำนวณจำนวนวันทำงาน
src/app.js        REST API ทั้งหมด (/api/...)
public/           หน้าเว็บ (HTML/CSS/JS ไม่ต้อง build)
test/             ชุดทดสอบ
```

## กติกาสำคัญ

- ใบลาหนึ่งใบต้องอยู่ภายในปีเดียวกัน (สิทธิ์วันลานับตามปีปฏิทิน)
- สิทธิ์คงเหลือ = สิทธิ์ต่อปี − วันที่อนุมัติแล้ว − วันที่รออนุมัติ
- ยกเลิกได้ทั้งใบที่รออนุมัติ และใบที่อนุมัติแล้วแต่ยังไม่ถึงวันลา
