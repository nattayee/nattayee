# 📅 ระบบนัดคิวผู้ป่วยใส่แร่ (Brachytherapy Appointment Queue)

เว็บแอปบน **Google Apps Script** สำหรับลงนัดผู้ป่วยใส่แร่

- กรอก **HN, ชื่อผู้ป่วย, แพทย์, จำนวน Fraction** แล้วเลือกวันเริ่ม/เวลา/รูปแบบการนัด
- ระบบสร้างวันนัดทุก Fraction ให้อัตโนมัติ (เช่น จ–ศ, จ/พฤ, สัปดาห์ละครั้ง, ทุก N วัน) และข้ามวันหยุดได้
- **กดปุ่มเดียว** → ลงนัดทุก Fraction ใน **Google Calendar** และ**บันทึกเบื้องหลังลง Google Sheet**
- เตือนเมื่อนัดซ้อนเวลากับผู้ป่วยรายอื่น และเตือนเมื่อ HN นั้นมีนัดค้างอยู่แล้ว
- ตารางนัดคิวแยกตามวัน ค้นหาได้ กด "มาแล้ว" / "ยกเลิก" / "ยกเลิกทั้งคอร์ส" ได้ (เมื่อยกเลิก นัดในปฏิทินจะถูกลบด้วย)

| ไฟล์ | หน้าที่ |
|---|---|
| `Code.gs` | ฝั่งเซิร์ฟเวอร์: บันทึกชีต, สร้าง/ลบ event ในปฏิทิน, ตรวจนัดซ้อน |
| `Index.html` | หน้าเว็บกรอกนัดและตารางนัดคิว |
| `appsscript.json` | ตั้งค่าโปรเจกต์ (timezone Asia/Bangkok, สิทธิ์ที่ใช้) |

> เปิด `Index.html` ในเบราว์เซอร์ตรง ๆ ได้เลยเพื่อลองหน้าตา (**โหมดทดลอง**) ข้อมูลจะเก็บไว้ในเบราว์เซอร์นั้นเท่านั้น ยังไม่บันทึกลงชีตหรือปฏิทิน

---

## วิธีติดตั้ง (ประมาณ 5 นาที)

1. สร้าง Google Sheet ใหม่ เช่น ตั้งชื่อว่า `นัดคิวใส่แร่`
2. ไปที่เมนู **ส่วนขยาย (Extensions) → Apps Script**
3. ในหน้า Apps Script:
   - วางเนื้อหาไฟล์ `Code.gs` ลงในไฟล์ `Code.gs` (ลบโค้ดเดิมออกก่อน)
   - กด **＋ → HTML** ตั้งชื่อว่า `Index` (ไม่ต้องพิมพ์ .html) แล้ววางเนื้อหาไฟล์ `Index.html`
   - (ไม่บังคับ) ไปที่ ⚙️ **Project Settings** → ติ๊ก *Show "appsscript.json" manifest file* แล้ววางเนื้อหา `appsscript.json`
     ถ้าไม่ทำ ให้ตั้ง Time zone ของโปรเจกต์เป็น **(GMT+07:00) Bangkok** ในหน้า Project Settings
4. เลือกฟังก์ชัน `setup` ที่แถบด้านบน แล้วกด **Run** → อนุญาตสิทธิ์ (Google Sheets + Google Calendar)
   ระบบจะสร้างชีต `Appointments`, `Doctors`, `Holidays`, `Settings` ให้
5. กด **Deploy → New deployment** → เลือกชนิด **Web app**
   - *Execute as*: **Me** (นัดจะลงในปฏิทินของบัญชีนี้)
   - *Who has access*: **Only myself** หรือ **Anyone within (องค์กร)** / **Anyone with Google account** ถ้าต้องการให้เจ้าหน้าที่คนอื่นใช้ด้วย
6. คัดลอก **Web app URL** ไปบุ๊กมาร์กไว้ใช้งาน
   (หรือเปิดจาก Google Sheet ผ่านเมนู **นัดคิวใส่แร่ → เปิดหน้าลงนัด**)

> แก้โค้ดภายหลัง: **Deploy → Manage deployments → ✏️ → Version: New version** เพื่อให้ URL เดิมใช้โค้ดใหม่

## ตั้งค่าในชีต

### ชีต `Doctors`
ใส่รายชื่อแพทย์ในคอลัมน์ A (หนึ่งชื่อต่อหนึ่งแถว) จะขึ้นเป็นตัวเลือกในฟอร์ม (พิมพ์ชื่ออื่นเองก็ได้)

### ชีต `Holidays`
ใส่วันหยุดในคอลัมน์ A รูปแบบ `yyyy-MM-dd` เช่น `2026-10-13` และชื่อวันหยุดในคอลัมน์ B
ถ้าติ๊ก "ข้ามวันหยุด" ระบบจะไม่นัดในวันเหล่านี้

### ชีต `Settings`

| คีย์ | ค่าเริ่มต้น | ความหมาย |
|---|---|---|
| `CALENDAR_ID` | (ว่าง) | ID ปฏิทินที่จะลงนัด ว่าง = ปฏิทินหลักของบัญชี **แนะนำให้สร้างปฏิทินแยก** เช่น "นัดใส่แร่" แล้วนำ Calendar ID (Google Calendar → การตั้งค่าปฏิทิน → ผสานรวมปฏิทิน) มาใส่ |
| `EVENT_PREFIX` | `[ใส่แร่]` | คำนำหน้าชื่อนัดในปฏิทิน |
| `SHOW_NAME_IN_CALENDAR` | `TRUE` | `FALSE` = ปฏิทินแสดงเฉพาะ HN ไม่แสดงชื่อผู้ป่วย |
| `LOCATION` | `ห้องใส่แร่ (Brachytherapy)` | สถานที่ในนัด |
| `DEFAULT_START_TIME` | `09:00` | เวลาเริ่มที่ตั้งไว้ในฟอร์ม |
| `DEFAULT_DURATION_MIN` | `60` | ระยะเวลาต่อ Fraction (นาที) |
| `MAX_PARALLEL` | `1` | จำนวนผู้ป่วยที่ทำพร้อมกันได้ในช่วงเวลาเดียว (ใช้ตรวจนัดซ้อน) |

## ข้อมูลที่บันทึกในชีต `Appointments`

หนึ่งแถวต่อหนึ่ง Fraction:
`เลขนัด | รหัสคอร์ส | วันที่บันทึก | HN | ชื่อ-สกุล | แพทย์ | Fraction ที่ | จำนวน Fraction | วันที่นัด | เวลาเริ่ม | เวลาสิ้นสุด | หมายเหตุ | สถานะ | Calendar Event ID | ผู้บันทึก`

สถานะ: `นัดแล้ว` → `มาตามนัด` หรือ `ยกเลิก`

ชื่อนัดในปฏิทินเป็นแบบ `[ใส่แร่] HN 6512345 สมหญิง ใจดี (Fx 1/4)` และในรายละเอียดมีชื่อแพทย์ หมายเหตุ และรหัสคอร์ส

## ข้อควรระวังด้านข้อมูลผู้ป่วย (PDPA)

- ใช้ปฏิทินแยกเฉพาะงาน และ**อย่าตั้งปฏิทินหรือชีตเป็นสาธารณะ** แชร์เฉพาะเจ้าหน้าที่ที่เกี่ยวข้อง
- ถ้าปฏิทินถูกแชร์กว้างหรือซิงก์ลงมือถือส่วนตัว ให้ตั้ง `SHOW_NAME_IN_CALENDAR` เป็น `FALSE`
- ควรใช้บัญชี Google ของหน่วยงาน (Google Workspace) แทนบัญชีส่วนตัว
