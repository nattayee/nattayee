# 📅 ระบบนัดคิวผู้ป่วยใส่แร่ (Brachytherapy Appointment Queue)

เว็บแอปบน **Google Apps Script** สำหรับลงนัดผู้ป่วยใส่แร่

- กรอก **HN, ชื่อผู้ป่วย, แพทย์, จำนวน Fraction** แล้วเลือกวันเริ่มและรูปแบบการนัด (ไม่ต้องระบุเวลา)
- **🌐 เปลี่ยนภาษาได้** ไทย / English ที่มุมขวาบน (วันที่แสดงตามภาษา: ไทยใช้ พ.ศ.) ระบบจำภาษาที่เลือกไว้ในเบราว์เซอร์
- **🌙 / ☀️ โหมดกลางคืน / กลางวัน** กดไอคอนที่มุมขวาบน
  - ครั้งแรกจะใช้ตามการตั้งค่าของอุปกรณ์ เมื่อกดเลือกแล้วระบบจะจำไว้
  - ไอคอนพระจันทร์ = กดเพื่อเปลี่ยนเป็นกลางคืน, ไอคอนพระอาทิตย์ = กดเพื่อเปลี่ยนเป็นกลางวัน
- **แพทย์เลือกจากรายชื่อ:** ทัศน์วรรณ อาษากิจ, ศิริรัตน์ เชื้อสำราญ, พัฒธิดา มโนรส, ทินกร จอมใจ (แก้ไขได้ในชีต `Doctors`)
- **รูปแบบการนัด** มี 3 แบบ
  - **ตามวันในสัปดาห์** (จ–ศ, จ/พฤ, สัปดาห์ละครั้ง ฯลฯ) และ **ทุก ๆ N วัน**: สร้างวันนัดให้อัตโนมัติ ข้ามวันหยุดได้
  - **เลือกวันเองตาม Fraction**: มีช่องวันที่ให้เลือก Fx 1, Fx 2, … ครบตามจำนวน Fraction
    - เมื่อสลับมาแบบนี้ ช่องจะตั้งต้นด้วยวันที่ที่ระบบสร้างไว้ แก้เฉพาะ Fx ที่ต้องการได้
    - เลือกวันเดียวกันได้ (เช่น ทำวันละ 2 Fx)
    - ถ้ายังเลือกไม่ครบ ระบบจะเตือนและไม่ให้บันทึก
- **กดปุ่มเดียว** → ลงนัดทุก Fraction ใน **Google Calendar** (เป็นนัดทั้งวัน) และ**บันทึกเบื้องหลังลง Google Sheet**
- ในแต่ละวันเรียงเป็น **คิวที่ 1, 2, 3…** ตามลำดับที่ลงนัด (นัดที่ยกเลิกไม่นับ)
- เตือนเมื่อ HN เดียวกันมีนัดในวันเดียวกันอยู่แล้ว (กันลงซ้ำ) แต่ยังลงได้ถ้ากดยืนยัน เช่น กรณีทำวันละ 2 Fx
- **🚨 แจ้งเตือนเมื่อวันใดเกิน 6 เคส**
  - ตอนลงนัด: แต่ละ Fx แสดงว่าวันนั้นมีนัดแล้วกี่เคส ถ้าจะเกินจะขึ้นเตือนให้ยืนยันก่อนบันทึก
  - แถบแจ้งเตือนสีแดงด้านบน แสดงทุกวันที่จะถึงซึ่งเกิน 6 เคส (คลิกเพื่อดูรายละเอียด)
  - ส่งอีเมลแจ้งเตือนได้ (ตั้ง `ALERT_EMAIL`) และบันทึกลงชีต `AccessLog`
- **🔒 ต้อง login Gmail ก่อนใช้งาน** ใช้ได้เฉพาะอีเมลที่อยู่ในชีต `Users` และบันทึกทุกการใช้งาน (เข้าใช้งาน / ลงนัด / ยกเลิก / มาตามนัด / ถูกปฏิเสธ) ลงชีต `AccessLog`
- **📊 แดชบอร์ด**
  - การ์ดสรุป: จำนวนเคสวันนี้ / สัปดาห์นี้ / ทั้งเดือน / จำนวนวันที่เกิน 6 เคส
  - กราฟแท่งจำนวนเคสต่อวัน มีเส้นเพดาน 6 เคส แท่งที่เกินเป็นสีแดง ชี้เพื่อดูรายชื่อ
  - ปฏิทินรายเดือน: แต่ละวันแสดงจำนวนเคสและรายชื่อตามคิว (ลำดับ HN ชื่อ)
  - คลิกวันเพื่อดูรายละเอียด: ตารางผู้ป่วยเรียงตามคิว สรุปจำนวนเคสแยกตามแพทย์ และปุ่มมาแล้ว/ยกเลิก
- ตารางนัดคิวแยกตามวัน ค้นหาได้ กด "มาแล้ว" / "ยกเลิก" / "ยกเลิกทั้งคอร์ส" ได้ (เมื่อยกเลิก นัดในปฏิทินจะถูกลบด้วย)

| ไฟล์ | หน้าที่ |
|---|---|
| `Code.gs` | ฝั่งเซิร์ฟเวอร์: ตรวจสิทธิ์ผู้ใช้, บันทึกชีต, log, สร้าง/ลบ event ในปฏิทิน, ตรวจนัดซ้ำและเคสเกิน |
| `Index.html` | หน้าเว็บกรอกนัด ตารางนัดคิว และแดชบอร์ด |
| `appsscript.json` | ตั้งค่าโปรเจกต์ (timezone Asia/Bangkok, สิทธิ์ที่ใช้, การ deploy) |

> เปิด `Index.html` ในเบราว์เซอร์ตรง ๆ ได้เลยเพื่อลองหน้าตา (**โหมดทดลอง**) กดปุ่ม "ใส่ข้อมูลตัวอย่าง" เพื่อดูแดชบอร์ด
> ข้อมูลในโหมดนี้เก็บไว้ในเบราว์เซอร์นั้นเท่านั้น ยังไม่บันทึกลงชีตหรือปฏิทิน

## วิธีติดตั้ง

1. สร้าง Google Sheet ใหม่ เช่น ตั้งชื่อว่า `นัดคิวใส่แร่`
2. ไปที่เมนู **ส่วนขยาย (Extensions) → Apps Script**
3. ในหน้า Apps Script:
   - วางเนื้อหาไฟล์ `Code.gs` ลงในไฟล์ `Code.gs` (ลบโค้ดเดิมออกก่อน)
   - กด **＋ → HTML** ตั้งชื่อว่า `Index` (ไม่ต้องพิมพ์ .html) แล้ววางเนื้อหาไฟล์ `Index.html`
   - ไปที่ ⚙️ **Project Settings** → ติ๊ก *Show "appsscript.json" manifest file* แล้ววางเนื้อหา `appsscript.json`
4. เลือกฟังก์ชัน `setup` ที่แถบด้านบน แล้วกด **Run** → อนุญาตสิทธิ์
   ระบบจะสร้างชีต `Appointments`, `Doctors`, `Holidays`, `Settings`, `Users`, `AccessLog` และใส่อีเมลของคุณในชีต `Users` เป็นผู้ดูแลระบบ
5. **สร้างปฏิทินกลาง** ใน Google Calendar เช่น "นัดใส่แร่"
   - นำ **Calendar ID** (การตั้งค่าปฏิทิน → ผสานรวมปฏิทิน) มาใส่ที่ `CALENDAR_ID` ในชีต `Settings`
   - แชร์ปฏิทินให้เจ้าหน้าที่ทุกคนด้วยสิทธิ์ **"ทำการเปลี่ยนแปลงกิจกรรม"**
6. **เพิ่มผู้ใช้งาน**
   - ใส่ Gmail ของเจ้าหน้าที่ในชีต `Users` (คอลัมน์ A = อีเมล, B = ชื่อ, C = `TRUE`)
   - แชร์ Google Sheet ให้อีเมลเหล่านั้นด้วยสิทธิ์ **ผู้แก้ไข (Editor)**
7. กด **Deploy → New deployment** → เลือกชนิด **Web app**
   - *Execute as*: **User accessing the web app**
   - *Who has access*: **Anyone with Google account**
8. คัดลอก **Web app URL** ส่งให้เจ้าหน้าที่
   - ครั้งแรกที่เปิด แต่ละคนต้อง login Gmail และกดอนุญาตสิทธิ์
   - ถ้าขึ้นหน้า "Google hasn't verified this app" ให้กด *Advanced → Go to … (unsafe)* เพราะเป็นสคริปต์ภายในที่สร้างเอง

> แก้โค้ดภายหลัง: **Deploy → Manage deployments → ✏️ → Version: New version** เพื่อให้ URL เดิมใช้โค้ดใหม่
> อัปเดตจากเวอร์ชันก่อน: วางโค้ดใหม่แล้ว Run `setup` อีกครั้ง ระบบจะเพิ่มชีตและค่าตั้งค่าที่ขาด (ข้อมูลเดิมยังอยู่) และต้องแก้ deployment เป็น *User accessing the web app* ตามข้อ 7
> ถ้าชีต `Appointments` เดิมมีคอลัมน์ "เวลาเริ่ม/เวลาสิ้นสุด" หรือ "ชนิด" (จากเวอร์ชันก่อน) ระบบจะลบคอลัมน์นั้นให้อัตโนมัติ ข้อมูลอื่นยังอยู่ครบ ส่วนนัดเดิมในปฏิทินไม่เปลี่ยน

### ทำไมต้อง "User accessing the web app"

ถ้าตั้งเป็น *Execute as: Me* Google จะไม่ส่งอีเมลของผู้ใช้ที่เป็น @gmail.com มาให้สคริปต์ จึงตรวจสิทธิ์หรือบันทึกว่าใครใช้งานไม่ได้
การรันในนามผู้ใช้ทำให้:
- ทุกคนต้อง login Google ก่อนเข้าใช้งาน
- ได้อีเมลจริงของผู้ใช้ทุกครั้ง
- เข้าได้เฉพาะคนที่ได้รับแชร์ชีตและอยู่ในชีต `Users`

## ตั้งค่าในชีต

### ชีต `Users` — ผู้มีสิทธิ์ใช้งาน
| อีเมล (Gmail) | ชื่อ | ใช้งาน (TRUE/FALSE) |
|---|---|---|
| staff1@gmail.com | พยาบาล ก | TRUE |

ตั้งเป็น `FALSE` เพื่อระงับสิทธิ์โดยไม่ต้องลบแถว (ควรเลิกแชร์ชีตด้วย)

### ชีต `AccessLog` — บันทึกการใช้งาน (หลังบ้าน)
`เวลา | อีเมล | การกระทำ | รายละเอียด`
การกระทำที่บันทึก: `เข้าใช้งาน`, `ลงนัด`, `ยกเลิกนัด`, `บันทึกมาตามนัด`, `แจ้งเตือนเกินเคส`, `ถูกปฏิเสธ`, `ลงนัดไม่สำเร็จ`
(คนที่ยังไม่ได้รับแชร์ชีตเลยจะเห็นหน้า "ไม่มีสิทธิ์" แต่จะไม่ถูกบันทึก เพราะสคริปต์เขียนชีตในนามคนนั้นไม่ได้)

### ชีต `Doctors`
รายชื่อแพทย์ในคอลัมน์ A (หนึ่งชื่อต่อหนึ่งแถว) แสดงเป็นตัวเลือกในฟอร์ม และระบบไม่รับชื่อแพทย์ที่ไม่อยู่ในรายการ

### ชีต `Holidays`
ใส่วันหยุดในคอลัมน์ A รูปแบบ `yyyy-MM-dd` เช่น `2026-10-13` และชื่อวันหยุดในคอลัมน์ B
ถ้าติ๊ก "ข้ามวันหยุด" ระบบจะไม่นัดในวันเหล่านี้ (แดชบอร์ดจะแสดงชื่อวันหยุดด้วย)

### ชีต `Settings`

| คีย์ | ค่าเริ่มต้น | ความหมาย |
|---|---|---|
| `CALENDAR_ID` | (ว่าง) | ID ปฏิทินกลาง **ต้องตั้ง** ไม่อย่างนั้นนัดจะไปลงปฏิทินส่วนตัวของผู้บันทึกแต่ละคน |
| `MAX_CASES_PER_DAY` | `6` | จำนวนเคสสูงสุดต่อวัน ถ้าเกินจะแจ้งเตือน |
| `ALERT_EMAIL` | (ว่าง) | อีเมลรับแจ้งเตือนเมื่อวันใดเกินจำนวนเคส คั่นหลายอีเมลด้วย `,` (ส่งจากบัญชีของผู้ที่ลงนัด) |
| `EVENT_PREFIX` | `[ใส่แร่]` | คำนำหน้าชื่อนัดในปฏิทิน |
| `SHOW_NAME_IN_CALENDAR` | `TRUE` | `FALSE` = ปฏิทินแสดงเฉพาะ HN ไม่แสดงชื่อผู้ป่วย |
| `LOCATION` | `ห้องใส่แร่ (Brachytherapy)` | สถานที่ในนัด |

(ถ้าชีตเดิมมี `DEFAULT_START_TIME`, `DEFAULT_DURATION_MIN`, `MAX_PARALLEL` ไม่ได้ใช้แล้ว ลบแถวทิ้งได้)

### ภาษา
- ข้อความบนหน้าเว็บอยู่ในตัวแปร `I18N` ใน `Index.html` (`th` / `en`) แก้คำหรือเพิ่มภาษาได้ที่นั่น
- ข้อความแจ้งข้อผิดพลาดจากเซิร์ฟเวอร์อยู่ในตัวแปร `MSG` ใน `Code.gs`
- ข้อมูลในชีตยังเป็นภาษาไทยเสมอ (เช่น สถานะ `นัดแล้ว`/`มาตามนัด`/`ยกเลิก`) หน้าเว็บแปลให้ตอนแสดงผลเท่านั้น
- ชื่อแพทย์ ชื่อผู้ป่วย ชื่อวันหยุด และ log ไม่แปล

"เคส" ที่นับ = นัด 1 Fraction ที่ยังไม่ถูกยกเลิก (สถานะ `นัดแล้ว` หรือ `มาตามนัด`)

## ข้อมูลที่บันทึกในชีต `Appointments`

หนึ่งแถวต่อหนึ่ง Fraction:
`เลขนัด | รหัสคอร์ส | วันที่บันทึก | HN | ชื่อ-สกุล | แพทย์ | Fraction ที่ | จำนวน Fraction | วันที่นัด | หมายเหตุ | สถานะ | Calendar Event ID | ผู้บันทึก (อีเมล)`

ลำดับคิวในแต่ละวันคิดจากลำดับแถวในชีต (ลงนัดก่อน = คิวก่อน) จึงไม่ควรเรียงลำดับ (sort) ชีตนี้ใหม่ ถ้าต้องการดูแบบเรียง ให้ใช้ตัวกรองหรือมุมมองตัวกรอง (filter view) แทน

สถานะ: `นัดแล้ว` → `มาตามนัด` หรือ `ยกเลิก`

นัดในปฏิทินเป็น**นัดทั้งวัน** ชื่อแบบ `[ใส่แร่] HN 6512345 สมหญิง ใจดี (Fx 1/4)` และในรายละเอียดมีชื่อแพทย์ หมายเหตุ รหัสคอร์ส และผู้บันทึก

## ข้อควรระวังด้านข้อมูลผู้ป่วย (PDPA)

- แชร์ชีตและปฏิทินเฉพาะเจ้าหน้าที่ที่เกี่ยวข้อง **อย่าตั้งเป็นสาธารณะ** หรือ "ทุกคนที่มีลิงก์"
- ถ้าปฏิทินซิงก์ลงมือถือส่วนตัว ให้ตั้ง `SHOW_NAME_IN_CALENDAR` เป็น `FALSE`
- เมื่อเจ้าหน้าที่ย้าย/ลาออก ให้ตั้ง `FALSE` ในชีต `Users` และเลิกแชร์ชีตกับปฏิทิน
- ตรวจดูชีต `AccessLog` เป็นระยะ
